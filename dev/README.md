# dev — локальный стенд (не прод)

Цель: гонять промпт и eval на ноутбуке, не имея GPU. Стенд **не EVA32**: базовые веса здесь
qwen2.5, а прод — DeepSeek V4-Flash на 8×H100. Меряем поведение *промпта* (тон, отказы, цитаты,
сопротивление инъекциям), а не качество знаний — знания придут из RAG.

Две модели, обе уже скачаны:

| Модель | Диск | RAM при работе | Для чего |
|---|---|---|---|
| `qwen2.5:3b` (по умолчанию) | 1.8 ГБ | ~2.5 ГБ | прогоны, когда на машине есть чужая работа |
| `qwen2.5:7b` | 4.4 ГБ | ~4.7 ГБ | когда нужен более сильный сигнал по промпту |

Ни та, ни другая не даёт права судить о качестве EVA32 — только о том, держатся ли правила промпта.
Перед прогоном посмотри свободную память (`make status`) и не запускай, если машина занята.

## Откуда берутся веса

Веса в git не кладём: 6.2 ГБ — это не исходники, а окружение. Вместо них в репозитории лежит
`dev/models.lock` — имя модели, sha256 блоба и размер, чтобы стенд был воспроизводим.
Дотянуть недостающее: `make pull-dev` (нужен запущенный демон).

Скачанные модели живут в общем сторе Ollama (`~/.ollama`), поэтому `ollama run` работает откуда
угодно, а блобы делятся между моделями одной базы.

## Запуск

```bash
make dev-serve               # поднять Ollama (демон, веса в RAM ещё не грузятся)

# прогон золотого набора на лёгкой модели
make eval-dev                # = qwen2.5:3b
make eval-dev DEV_MODEL=qwen2.5:7b REPEAT=3

make dev-stop                # выгрузить модель и погасить демон
```

Результаты — в `eval/results/eval-YYYYmmdd-HHMMSS.json`, вместе с `bundle` (хеш промпта + конфига).

## Свой Modelfile (для интерактивного чата)

`dev/Modelfile` — та же персона, что в `prompts/system.ru.md`, но прошитая в модель:
удобно `ollama run eva32-dev`. Сборка:

```bash
ollama create eva32-dev -f dev/Modelfile
```

Если Ollama не имеет прав писать в `~/.ollama`, задайте свой каталог:
`OLLAMA_MODELS=/path/with/space ollama serve`. Для eval это не нужно — Modelfile там не
требуется, промпт уходит в запросе, как и в проде.

## Чего стенд не проверяет

- Качество знаний и работу с каталогом — это eval на проде с реальным RAG-контекстом.
- Скорость и память: `num_ctx 8192`, 16 ГБ RAM — цифры нельзя переносить на H100.
- Thinking-режим DeepSeek: у qwen его нет, `thinking: off` из конфига здесь не проверяется.
