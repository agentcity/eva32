# Словарь ударений для Silero v4_ru (задача 0222).

# Формат строки: слово<TAB>разметка
#   разметка — то же слово со знаком "+" перед ударной гласной;
#   Silero понимает "+" и произносит слово с правильным ударением.
#
# Пример:  Колобок<TAB>Колоб+ок
#
# Файл дополняет встроенный словарь eva/ru_stress.py и перекрывает его:
# если слово уже есть в коде, здешняя запись главнее. Строки с "#" и пустые
# игнорируются. Битая строка (нет таба, разметка не совпадает со словом,
# "+" не перед гласной) не роняет синтез: в лог уходит предупреждение с
# номером строки, строка пропускается.
