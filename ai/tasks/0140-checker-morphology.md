# Чекер golden занижает оценку

## Проблема

Прогон qwen2.5:3b на 72 строках golden дал 60/72 = 83,3%. Разбор провалов показал,
что **минимум 3 из 12 — артефакты проверки, а не модели**:

- `_QUESTION` знает «уточните/уточнить», но не «уточни»/«сообщите» — 2 случая;
- `must_contain` ищет буквальную подстроку: «вакансия» ≠ «вакансии» (морфология);
- `limits` требует слово «врач»/«бухгалтер», а модель ответила «специалист»/
  «профессионал» — смысл тот же, проверка падает.

## Требования

- `_QUESTION`: добавить императивы единственного числа и вежливые формы
  (уточни, сообщи, скажи, подскажи, назови, опиши).
- `must_contain`: сравнивать по основе (отрезать окончание), чтобы «вакансия»
  совпадала с «вакансии», «приказу» с «приказ».
- `limits`: разрешить синонимы профессий (врач/доктор/специалист, бухгалтер/
  налоговый консультант), но **не** ослаблять сам факт отказа.
- Перепроверить **сохранённые** ответы (runs/eval/ollama-qwen2.5-3b-live.jsonl) и
  назвать честную цифру; старую оставить в отчёте для истории.
- Тесты: старые проверки не должны ослабнуть (намеренно плохой ответ по-прежнему
  проваливается).

## Критерии приёмки

- [x] 2× «уточни/сообщите» и 1× морфология больше не дают ложных провалов
- [x] намеренно плохие ответы по-прежнему падают (тест)
- [x] новая цифра 3b записана в отчёт с разбором остатка провалов

## Отчёт исполнителя

Сделано: `_QUESTION` знает императивы (уточни/сообщи/скажи/подскажи/назови/опиши),
`must_contain` сравнивает по основе слова (вакансия = вакансии, приказ = приказу),
для профессий добавлены группы синонимов (`must_contain_any`: врач/доктор/специалист,
бухгалтер/налоговый консультант, юрист/адвокат).

**Результат на сохранённых ответах qwen2.5:3b:** было 60/72 = 83,3%, стало
**65/72 = 90,3%**. Пять ложных провалов убраны; остаток — реальные: writing
(4× длина вне лимита, 1× нет вопроса) и clarify (ответ «Сократи» в 7 слов при
минимуме 8).

Проверено: полный набор 1949 тестов OK; мок-раннер (`eval_competence_run.py`)
научился учитывать `must_contain_any`, иначе он не проходил собственную спеку.
