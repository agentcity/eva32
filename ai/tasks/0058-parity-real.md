# Сверка настоящей модели

## Проблема

Задача 0006 (полная модель в ВТМ) не закрыта: синтетика совпадает, а на реальных
весах никто не сверял. Без этого обученную модель нечем проверить.

## Решение

`tools/parity_real.py` на GPU-машине:
1. transformers грузит Qwen2.5-1.5B-Instruct, снимает логиты последней позиции;
2. тот же forward с тернарными весами (`qat.model.apply_ternary`) — **эталон для
   порога**, чтобы мерить рантайм, а не ошибку квантования;
3. экспорт через `qat.export` → компиляция через `tools/vtm_compile.py`;
4. прогон в C (`vtm run`) + C-проба, снимающая тензор logits;
5. сверка: max|Δ|, argmax, top-5; порог argmax совпал и max|Δ| < 1e-2.

## Критерии приёмки

- [x] `--dry-run` работает без torch
- [x] 59 тестов зелёные, полный набор не сломан
- [x] явные отказы: rope_scaling, partial_rotary, sliding window, не-silu
- [x] `--scale-dtype float32` изолирует округление масштабов

## Отчёт исполнителя

Написан и проверен без torch (dry-run + 59 тестов). Реальный прогон — на арендованном
GPU. Известные ограничения записаны: fp32-эмбеддинги 1.5B требуют 8–10 ГиБ RAM в
Python-компиляторе (fallback — тритовые эмбеддинги), скалярное ядро может считать
промпт минутами, eps=1e-6 в компиляторе округляется до imm=0.
