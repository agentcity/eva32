# Живой круг вместо строчки статуса

## Зачем
Сейчас состояние Евы — это текст («слушаю…», «отвечает…»). Нужно видеть состояние
сразу: большой круг, который **дышит** вместе с голосом.

## Требования
1. **Круг** (NSView, Core Graphics/Core Animation, без внешних зависимостей):
   - `idle` — спокойное дыхание (медленная пульсация), приглушённый цвет;
   - `listening` — кольцевая волна по громкости микрофона (реальный RMS),
     реакция на голос без задержки (<100 мс);
   - `thinking` — вращающаяся дуга/две волны внутри, пульсация быстрее;
   - `speaking` — волна по громкости воспроизведения (AVAudioPlayer metering);
   - `error` — короткая красная вспышка + текст ошибки рядом.
2. **Данные уровней**:
   - микрофон: RMS из аудио-тапа (сглаживание, чтобы не дёргалось);
   - озвучка: `AVAudioPlayer.isMeteringEnabled = true`, `updateMeters()`,
     `averagePower(forChannel:)` по таймеру 30 Гц.
3. **Переходы**: idle → listening (⌥Space) → thinking (текст ушёл, ответа ещё нет)
   → speaking (звук идёт) → idle. Плавно (0.2–0.3 с), без рывков.
4. Круг масштабируется с окном, не ломает существующую вёрстку (окно ~580×520).
5. Настройки: галочка «анимация» (для слабых машин) — без неё круг статичен.

## Критерии приёмки
- [ ] круг есть в окне, состояния различимы на глаз
- [ ] на речь реагирует (волна идёт), на тишину — нет
- [ ] thinking виден от отправки до первого текста, speaking — пока играет звук
- [ ] CPU в покое <2% (круг не жжёт батарею), сборка `tools/build_eva_app.sh`
- [ ] README/`docs/voice-app.md`: как выглядит и что означает

## Отчёт исполнителя

**Статус:** готово к приёмке; живая проверка микрофона остаётся за человеком
(см. ниже).

### Что сделано

- Новый `apps/eva/Sources/CircleView.swift`: `NSView` с `draw(_:)` на Core
  Graphics, состояние `EvaCircleState` (`idle/listening/thinking/speaking/error`).
  - `idle` — приглушённый серо-бирюзовый диск, медленное «дыхание» ~4,5 с;
  - `listening` — синие расходящиеся кольца + насечки, амплитуда от RMS;
  - `thinking` — фиолетовый диск, две вращающиеся дуги и пульс;
  - `speaking` — зелёные «жидкие» волны по краю диска от громкости плеера;
  - `error` — красная вспышка ~1,2 с, ударная волна и текст ошибки под кругом.
  - цвет состояния перетекает за 0,25 с; уровень сглаживается (атака 35 мс,
    отпускание 120 мс); таймер 30 Гц, при невидимом окне кадры не рисуются.
- `SpeechRecorder`: RMS считается прямо в аудио-тапе (`bufferSize` 2048,
  ≈43 мс при 48 кГц) в неизолированном `LevelMeter` под замком; `@MainActor`
  ничего не захватывает. Тикер 30 Гц на главном акторе читает уровень и
  отдаёт его кругу. Тап по-прежнему `@Sendable`, `RequestSink` расширен
  метром, а не состоянием рекордера.
- `VoicePlayer`: `isMeteringEnabled = true`, `updateMeters()` /
  `averagePower(forChannel:)` по таймеру 30 Гц; уровень уходит в круг, при
  остановке/конце фразы сбрасывается в 0.
- `AppDelegate`: одно место принятия решения о состоянии
  (`refreshVisualState`) с приоритетом ошибка → микрофон → «думаю» → «говорю» →
  покой; переходы логируются строками `круг: было → стало — причина`.
  «Думаю» держится до первого видимого текста, а при включённой озвучке — до
  первого звука, чтобы круг не мигал в idle между токеном и TTS.
- `MainWindowController`: круг добавлен верхним блоком; высота — 28 % ширины
  окна (110–240 pt), поэтому он масштабируется и не ломает ответ/поле ввода.
  Окно по умолчанию 580×560 (content), минимум 460×460.
- `Settings` / `SettingsWindowController`: ключ `eva.animateCircle` (по
  умолчанию `true`) и галочка «Анимация круга (меньше CPU)»; выключение сразу
  перестраивает открытое окно, таймер не создаётся.
- `docs/voice-app.md`: раздел «Большой круг состояния», таблица настроек,
  примеры строк журнала, оговорка про CPU и слабые машины.
- Список файлов `tools/build_eva_app.sh` не трогал: там glob `*.swift`.

### Чем проверено

1. Сборка: `sh tools/build_eva_app.sh` — без ошибок и предупреждений,
   `build/EVA.app` 0,5 МБ, ad-hoc подпись валидна.
2. Старые самопроверки: `--selftest-text` — все 6 проверок OK, exit 0;
   `--version` — exit 0; `--selftest-speech` — exit 0 (ru-RU on-device=true,
   микрофон разрешён). `--selftest-*` не менялись.
3. Живой сценарий чата и озвучки прогнан на временном mock-сервере SSE
   (`/tmp`, не в репозитории; реальный `tools/chat_server.py` не трогался).
   В журнале:

   ```text
   круг: idle → thinking — вопрос ушёл
   круг: thinking → speaking — озвучка пошла
   круг: speaking → idle — озвучка кончилась
   ```

   Т.е. thinking виден до звука, speaking — пока играет WAV.
4. Ошибка: запуск с несуществующим сервером дал

   ```text
   круг: idle → thinking — вопрос ушёл
   круг: thinking → error — сеть: Не удалось подключиться к серверу.
   круг: error → idle — вспышка ошибки прошла
   ```

5. CPU в покое (окно открыто, анимация включена): **0,22 %** за 5 с
   (`proc_pidinfo`, 500×735-окно, M-серия), потоков 13, RSS 85 МБ.
   С `eva.animateCircle=false`: **0,01 %** за 5 с (таймер не создаётся).
   После проверки ключ удалён, настройки возвращены как были.
6. Отрисовка: отдельный offscreen-стенд (вне репозитория) отрендерил все пять
   состояний в PNG. Центр диска: idle (95,126,137), listening (80,140,195),
   thinking (107,102,199), speaking (90,165,131), error (207,74,72) — состояния
   различимы по цвету; у listening/error границы шире диска за счёт волн.
   Окно приложения снято и проверено попиксельно: круг есть в верхнем блоке,
   диаметр диска ≈109 pt при ширине окна 500 pt.
7. `LevelMeter` проверен на синтетических буферах 2048 кадров:
   тишина `0.000`, тихий сигнал `0.140`, речь `0.540`, громко `0.878`.
   Буфер 43 мс + атака 35 мс укладываются в требование «<100 мс».

### Что не проверено автоматически

- **Живой микрофон**: у пересобранного ad-hoc бандла
  `SFSpeechRecognizer.authorizationStatus == notDetermined`, поэтому первый
  ⌥Space показывает системный запрос разрешения на распознавание речи, который
  нельзя нажать из агентской сессии. Код тапа и `LevelMeter` проверены
  синтетикой, но «сказать в микрофон и увидеть волну» должен человек: ⌥Space →
  «привет» → ⌥Space. Микрофон при этом уже разрешён (`3`).
- Галочка «Анимация» проверена через `eva.animateCircle` (CPU 0,01 %); клик по
  ней в окне настроек глазами не снимался.
