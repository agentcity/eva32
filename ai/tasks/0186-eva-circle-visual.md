# Живой круг вместо строчки статуса

## Зачем
Сейчас состояние Евы — это текст («слушаю…», «отвечает…»). Нужно видеть состояние
сразу: большой круг, который **дышит** вместе с голосом.

## Требования
1. **Круг** (NSView, Core Graphics/Core Animation, без внешних зависимостей):
   - `idle` — спокойное дыхание (медленная пульсация), приглушённый цвет;
   - `listening` — кольцевая волна по громкости микрофона (реальный RMS),
     реакция на голос без задержки (<100 мс);
   - `thinking` — вращающаяся дуга/две волны внутри, пульсация быстрее;
   - `speaking` — волна по громкости воспроизведения (AVAudioPlayer metering);
   - `error` — короткая красная вспышка + текст ошибки рядом.
2. **Данные уровней**:
   - микрофон: RMS из аудио-тапа (сглаживание, чтобы не дёргалось);
   - озвучка: `AVAudioPlayer.isMeteringEnabled = true`, `updateMeters()`,
     `averagePower(forChannel:)` по таймеру 30 Гц.
3. **Переходы**: idle → listening (⌥Space) → thinking (текст ушёл, ответа ещё нет)
   → speaking (звук идёт) → idle. Плавно (0.2–0.3 с), без рывков.
4. Круг масштабируется с окном, не ломает существующую вёрстку (окно ~580×520).
5. Настройки: галочка «анимация» (для слабых машин) — без неё круг статичен.

## Критерии приёмки
- [ ] круг есть в окне, состояния различимы на глаз
- [ ] на речь реагирует (волна идёт), на тишину — нет
- [ ] thinking виден от отправки до первого текста, speaking — пока играет звук
- [ ] CPU в покое <2% (круг не жжёт батарею), сборка `tools/build_eva_app.sh`
- [ ] README/`docs/voice-app.md`: как выглядит и что означает
