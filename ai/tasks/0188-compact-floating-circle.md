# Оставить только круг Евы

## Зачем
Разговор с Евой не должен занимать окно. Свернул — на экране только круг,
в правом нижнем углу, поверх других окон: видно, слушает она или думает.

## Требования
1. **Кнопка «Свернуть»** в главном окне (и `⌘M`): окно скрывается,
   показывается **компактное окно** — только круг.
2. **Компактное окно**: borderless, `NSWindow.Level.floating`, прозрачный фон,
   размер 120–160 pt, позиция по умолчанию — правый нижний угол экрана с
   отступом 24 pt; тащится мышью, позиция запоминается в UserDefaults и
   восстанавливается; при смене экрана/разрешения — зажимается в видимую область.
3. **Состояния круга работают в компактном режиме** (idle/listening/thinking/
   speaking/error) — тот же визуальный источник, без второй копии логики.
4. **Клик по кругу** — развернуть главное окно (компактное прячется).
   Двойной клик — начать/закончить слушать (как ⌥Space).
5. **Контекстное меню** (правый клик): «Развернуть», «Настройки», «Выход».
6. Компактное окно не мешает работе: не забирает фокус (`NSWindow.StyleMask.nonactivatingPanel`),
   не появляется в Dock, не перекрывает строку меню.
7. Настройка «Компактный режим при запуске» (по умолчанию выкл).

## Критерии приёмки
- [x] «Свернуть» → главное окно исчезло, круг в правом нижнем углу поверх окон
- [x] состояния в мини-режиме обновляются
- [x] клик разворачивает, двойной клик — слушает (обработчики — в самопроверке;
      живой жест мышью — за человеком)
- [x] позиция запоминается между запусками
- [x] CPU в простое не вырос (замер до/после: 0,22–0,26 % против 0,25 %)
- [x] `sh tools/build_eva_app.sh` без ошибок, `--selftest-*` живы

## Отчёт исполнителя

**Статус:** готово к приёмке. Компактный круг сделан, сборка и все
самопроверки зелёные, живой запуск проверен через `CGWindowList` и журнал.
Жесты настоящей мышью (клик/двойной клик/правый клик/перетаскивание) в
агентской сессии синтезировать нельзя (система не доставляет `CGEvent`
без Accessibility), поэтому те же обработчики вызваны программно в
`--selftest-compact`, а ручной чек-лист — ниже.

### Что сделано

1. **`apps/eva/Sources/CircleHub.swift` (новый) — один источник состояния.**
   Состояние по-прежнему выбирает `AppDelegate.refreshVisualState`; хаб лишь
   раскладывает готовое состояние/уровень/ошибку/ожидание/follow-up по
   зарегистрированным `CircleView`. Новый круг при регистрации сразу получает
   снимок, поэтому порядок «создали окно — показали» не важен. Ссылки на вью
   слабые; `MainWindowController` и `CompactWindowController` подключаются к
   одному и тому же хабу из `AppDelegate.init`.
2. **`apps/eva/Sources/CompactWindowController.swift` (новый) — само окно.**
   - `NSPanel` 140×140 pt (требование 120–160), styleMask
     `[.borderless, .nonactivatingPanel]`, `level = .floating`, прозрачный фон,
     без тени, без анимации появления, `canBecomeKey = false`,
     `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]`.
   - Показ — `orderFrontRegardless()` (без `NSApp.activate`); в
     `CGWindowList` окно видно как отдельное окно слоя 3.
   - Позиция: по умолчанию `visibleFrame.maxX - 140 - 24`,
     `visibleFrame.minY + 24`; перетаскивание вручную по `mouseDragged`
     (окно двигается за мышью, каждый шаг зажимается в `visibleFrame`);
     сохранение — `eva.compactX`/`eva.compactY`, восстановление при показе;
     смена экрана/разрешения — наблюдатель
     `didChangeScreenParameters` + `windowDidChangeScreen`, при отключении
     монитора окно переезжает в `visibleFrame` основного.
   - Клик: одиночный ждёт `NSEvent.doubleClickInterval` (Timer в режиме
     `.common`) и разворачивает; двойной отменяет таймер и зовёт
     «слушать/остановить»; перетаскивание отличается по смещению >2 pt.
     Правый клик — меню «Развернуть», «Настройки…», «Выход».
   - `CompactLayout` — чистая геометрия (угол, зажатие, выбор экрана), её и
     проверяет самопроверка без окна.
3. **`AppDelegate.swift` — режим вида.**
   - `isCompact`, единые `collapseToCompact(reason:)` /
     `expandFromCompact(reason:)`; кнопка «Свернуть», `⌘M` («Вид → Свернуть в
     круг») и настройка при запуске идут через один метод, поэтому окно и круг
     не могут быть видны одновременно.
   - Журнал: `вид: свёрнут — <причина>; круг …, главное окно скрыто`,
     `вид: развёрнут — <причина>; круг скрыт`, `вид: запуск в фоне — только
     статус-бар`.
   - В компактном режиме `⌥Space`, «Привет, Ева» и follow-up не разворачивают
     окно (`startListening(present: false)`); `ask()` не всплывает на каждый
     ответ, но `window.prepare()` собирает скрытое окно, чтобы вопрос и ответ
     были на месте после разворота.
   - `settingsChanged` применяет «Анимацию круга» к обоим кругам.
4. **`MainWindowController.swift`** — кнопка «Свернуть» в ряду управления,
   `hide()`, `prepare()`; круг больше не хранится локально, а регистрируется в
   хабе (методы-прокси `setVisualState`/`setCircleLevel`/… удалены).
5. **`Settings.swift` + `SettingsWindowController.swift`** — ключ
   `eva.startCompact`, галочка «Запускаться свёрнутым (только круг)» (по
   умолчанию **выключена**, применяется при следующем запуске), подсказка про
   `⌘M`; запись в журнал `старт-свёрнутым=true/false`.
6. **`SelfTest.swift` + `LaunchOptions.swift`** — новая самопроверка
   `--selftest-compact` (подробности ниже).
7. **`docs/voice-app.md`** — раздел «Компактный режим: только круг», строки в
   таблицах действий и настроек, команда самопроверки, строки журнала,
   результаты замеров и риски.

### Как проверено

Сборка (Swift 6, без предупреждений):

```bash
sh tools/build_eva_app.sh
# == готово: .../build/EVA.app (0.7 МБ)
```

Самопроверки (все код 0):

```bash
build/EVA.app/Contents/MacOS/EVA --selftest-text       # все проверки текста прошли
build/EVA.app/Contents/MacOS/EVA --selftest-wake       # все проверки wake-слова прошли
build/EVA.app/Contents/MacOS/EVA --selftest-followup   # все проверки follow-up прошли
build/EVA.app/Contents/MacOS/EVA --selftest-compact    # все проверки компактного круга прошли
build/EVA.app/Contents/MacOS/EVA --version
```

`--selftest-compact` проверяет:

- размер 140 pt в пределах 120–160, «запускаться свёрнутым» по умолчанию off;
- позиция по умолчанию — правый нижний угол, отступ 24 pt (на этой машине
  `visibleFrame = 0,55 1728×1029` → `1564,79`);
- зажатие окна за левым/нижним, правым/верхним краем, на втором экране и после
  его отключения (чистая `CompactLayout`, без окна);
- живое окно: 140×140, `[.borderless, .nonactivatingPanel]` (rawValue 128),
  `level == .floating`, прозрачный фон; `CGWindowList` находит ровно одно окно
  нашего pid на слое floating, его frame в координатах AppKit `1564,79
  140×140` совпадает с `NSWindow.frame` и лежит внутри `visibleFrame`
  (`maxY=219 ≤ 1084`, строка меню не перекрыта);
- один источник состояния: два разных `CircleView` (162 и 140 pt), подключённые
  к одному `CircleHub`, получают одно и то же состояние, ошибку, ожидание и
  follow-up — второй копии логики нет;
- фокус: `frontmostApplication` до/после показа тот же, `NSApp.isActive ==
  false`, activation policy `.accessory`;
- клики: двойной клик — «слушать» и отмена отложенного разворота, одиночный —
  разворот; состав правого меню ровно «Развернуть», «Настройки…», «Выход»;
- позиция: перетаскивание пишет `eva.compactX/Y`, новый контроллер встаёт туда
  же; сохранённая позиция «вне экрана» (9000,9000) зажимается в
  `visibleFrame`; после `hide()` окно не на экране. Позиция пишется в отдельный
  домен `com.eva32.eva.selftest.compact` и удаляется — настройки настоящего
  круга не трогаются.

Живое приложение (собранный бандл, `open -n`, журнал
`~/Library/Logs/EVA/eva.log`, внешний `CGWindowList`-пробник):

```text
настройки: … старт-свёрнутым=true
компакт: круг показан — 1564,79 140×140 level=3 (floating=3)
вид: свёрнут — запуск свёрнутым (настройка); круг 1564,79 140×140, главное окно скрыто
```

`CGWindowList` для этого запуска: одно видимое окно `Ева — круг`, слой 3,
`140×140`, appkit-frame `1564,79`, `insideVisible=true`, `overMenuBar=false`;
главное окно `Ева` существует, но `onscreen=false`; frontmost — прежнее
приложение, окно Евы неактивно. Обычный запуск (без галочки): видно только
главное окно `580×735`, круга нет. `--background`: окон нет вовсе,
`вид: запуск в фоне — только статус-бар`.

CPU в покое (свой замер через `proc_pid_rusage`, `animateCircle=true`):
`--background` 0,23 %, свёрнутый 0,22–0,26 %, развёрнутый 0,25 % — роста нет,
свёрнутый режим не дороже большого круга.

### Что осталось за человеком (2 минуты)

1. `open build/EVA.app`, нажать «Свернуть» — остаётся круг справа снизу;
   в журнале `вид: свёрнут — кнопка «Свернуть»`.
2. Клик по кругу — окно вернулось, круг исчез, ответ на месте
   (`вид: развёрнут — клик по кругу`).
3. Свернуть, дважды кликнуть по кругу — круг синеет «слушаю», окно не
   разворачивается; второй двойной клик останавливает.
4. Правый клик — меню из трёх пунктов; «Настройки…» и «Выход» работают.
5. Перетащить круг на другой монитор/в другой угол, перезапустить Еву — круг
   там же (или зажат в видимую область, если монитор убрали).
6. При активном главном окне нажать `⌘M` — то же, что «Свернуть».
7. В настройках включить «Запускаться свёрнутым», перезапустить — сразу
   только круг.

### Риски и ограничения

- **Клик с задержкой.** Одиночный клик разворачивает через
  `NSEvent.doubleClickInterval` — иначе двойной клик не отличить от двух
  одиночных. Для кнопки «Развернуть» это ощутимая, но предсказуемая пауза.
- **Клавиатура у неактивной панели.** `nonactivatingPanel` не забирает фокус,
  поэтому `⌘M` работает только когда главное окно активно; в свёрнутом режиме
  для клавиатуры Ева остаётся фоновым приложением (это и есть цель
  требования 6). Глобальный `⌥Space` работает всегда.
- **Правый клик/перетаскивание живьём не проверены** (нет права синтезировать
  мышь в агентской сессии). Обработчики те же, что в `--selftest-compact`, но
  сам жест стоит проверить по чек-листу; если macOS не отдаст правый клик
  неактивной панели, меню откроется после первого клика — тогда это лечится
  добавлением пункта в статус-бар.
- **Скрытое главное окно не бесплатно.** При сворачивании окно теперь
  собирается (если ещё не было) и остаётся в памяти; его круг тикает 30 Гц,
  но кадры не рисуются (`window.isVisible == false`), на замерах это не видно.
- **Позиция в общем домене.** `eva.compactX/Y` не привязаны к конкретному
  экрану: при смене конфигурации позиция зажимается в видимую область, но
  «вернуться на тот же второй монитор» после его повторного подключения окно
  не пытается — сознательно, чтобы не прыгать за курсором.
- **Журнал в агентской сессии.** Песочница этой сессии запрещает запись в
  `~/Library/Logs`, поэтому прямой запуск бинаря писал только в stderr;
  строки журнала выше сняты с запуска через LaunchServices (`open -n`). Это
  ограничение среды, не приложения.
- **CPU-замер** сделан на этой машине (`proc_pid_rusage`, 5–6 с); на слабых
  машинах абсолютные проценты будут другими, но соотношение «свёрнутый ≤
  развёрнутый» сохраняется: оба круга — один и тот же `CircleView`.
