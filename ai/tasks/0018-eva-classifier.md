# Гибрид: eva-classifier

Контракт — `docs/hybrid.md`, решение — `docs/adr/0009-hybrid-router.md`.
Читать оба до начала работы.

## Проблема

Классификатор маршрута без сети: по тексту решает, хватит ли малой модели.

## Требования

- `classify(text, cfg) -> Route` с confidence и reason.
- Признаки: длина, маркеры рассуждения (почему/объясни/сравни/напиши код/переведи/посчитай),
  доля латиницы, наличие факта из каталога, вопрос «как»/«что такое».
- Пороги — в config (не хардкод в функции), чтобы настраивать без правки кода.
- Никаких сетевых вызовов.

## Критерии приёмки

[ ] `python3 -m unittest tests.test_classifier -v` зелёный
[ ] 20 примеров размечены, ≥17 совпадают с ожидаемым маршрутом
[ ] пустой текст и мусор — не падает, возвращает route с reason

## Контекст и ограничения

- Зона: eva/classifier.py, tests/test_classifier.py
- Другие файлы не трогать: над репозиторием работают восемь агентов.
- Только stdlib Python, без сети в тестах, без установки пакетов.
- Не коммитить: сдавать правки и отчёт.

## Отчёт исполнителя

Сделано: `eva/classifier.py` (правила без сети, пороги из конфига), 22 теста,
20 размеченных примеров.

Проверено архитектором на живых примерах:
- «Сколько стоит тариф Старт?» → skill (catalog_fact: pricing, 0.90)
- «Какие часы работы?» → skill, «Как вернуть деньги?» → skill
- «Почему небо голубое?» → big (reasoning: почему, 0.85)
- «Напиши код на Python…» → big
- «Привет» → small (0.90), «asdfgh» → small (garbage, 0.25)
- порог `classifier_long_chars=10` меняет маршрут — конфиг реально управляет

Риски приняты: «как» и «что такое» уходят в big даже для простых how-to (ошибка
в дорогую сторону, но не в качество); 100% на 20 примерах — это своя разметка,
обобщение покажет только eval (0019).
