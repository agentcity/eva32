# Ева не знает, который час

## Зачем
Модель отвечает из весов: «сейчас 2023 год», курс валюты выдумывает. Нужны
**свежие данные в контексте вопроса**, а не «интернет внутри модели».

## Решение — не tool-calling, а пре-роутер (для 3B надёжнее)
Перед генерацией сервер распознаёт намерение и **подкладывает факт в промпт**;
модель только формулирует ответ. Детерминированно, без обучения и без
поддержки tool-вызовов в рантайме.

## Скиллы (все без ключей)
1. **Время/дата** — локальные часы сервера (`datetime.now()`), таймзона
   Europe/Moscow, «сегодня/завтра/понедельник» по календарю. Сети не нужно.
2. **Курсы валют ЦБ РФ** — `https://www.cbr.ru/scripts/XML_daily.asp` (XML,
   без ключа), кэш на час; USD/EUR/CNY и др.
3. **Котировки MOEX** — ISS API без ключа:
   `https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities/{TICKER}.json`
   (цена последней сделки, изменение за день), кэш 60 с; тикеры латиницей
   (SBER, GAZP, YNDX) и русские названия (Сбер, Газпром) → маппинг.
4. **Погода** — опционально, `wttr.in/?format=j1` (без ключа), если время
   останется.

## Требования
1. Новый `eva/tools/` (или `eva/skills/fresh.py`): функции `now_info()`,
   `currency_rate(code)`, `stock_quote(ticker)`; таймауты 3–5 с, кэш,
   graceful degradation (сеть упала → «не удалось получить, вот что знаю»).
2. **Роутер намерений** в `tools/chat_server.py` и `tools/chat.py`:
   регулярки/ключевые слова («который час», «сколько времени», «курс доллара»,
   «какой курс евро», «цена акции Сбер», «сколько стоит акция X»); найденное
   намерение → факт в системный/контекстный блок вида
   `[Факт: 2026-11-26 15:30 MSK, курс USD = 78.12 ₽ (ЦБ РФ)]`.
3. Модель **не должна** выдумывать: правило в промпте «если в блоке [Факт]
   есть данные — используй только их».
4. Тесты: парсеры XML/JSON на фикстурах (без сети), роутер намерений
   (20+ фраз), деградация без сети, кэш; живые прогоны — вручную.
5. Живая проверка: «который час» → текущее время; «курс доллара» → цифра ЦБ;
   «цена акции Сбер» → цифра MOEX.

## Критерии приёмки
- [ ] «который час» отвечает реальным временем (MSK)
- [ ] «курс доллара» — реальный курс ЦБ, не выдумка
- [ ] «цена акции Сбер» — реальная цена MOEX
- [ ] без сети — понятная деградация, не падение
- [ ] тесты на фикстурах, полный набор зелёный
