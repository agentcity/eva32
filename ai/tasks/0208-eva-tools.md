# Ева не знает, который час

## Зачем
Модель отвечает из весов: «сейчас 2023 год», курс валюты выдумывает. Нужны
**свежие данные в контексте вопроса**, а не «интернет внутри модели».

## Решение — не tool-calling, а пре-роутер (для 3B надёжнее)
Перед генерацией сервер распознаёт намерение и **подкладывает факт в промпт**;
модель только формулирует ответ. Детерминированно, без обучения и без
поддержки tool-вызовов в рантайме.

## Скиллы (все без ключей)
1. **Время/дата** — локальные часы сервера (`datetime.now()`), таймзона
   Europe/Moscow, «сегодня/завтра/понедельник» по календарю. Сети не нужно.
2. **Курсы валют ЦБ РФ** — `https://www.cbr.ru/scripts/XML_daily.asp` (XML,
   без ключа), кэш на час; USD/EUR/CNY и др.
3. **Котировки MOEX** — ISS API без ключа:
   `https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities/{TICKER}.json`
   (цена последней сделки, изменение за день), кэш 60 с; тикеры латиницей
   (SBER, GAZP, YNDX) и русские названия (Сбер, Газпром) → маппинг.
4. **Погода** — опционально, `wttr.in/?format=j1` (без ключа), если время
   останется.

## Требования
1. Новый `eva/tools/` (или `eva/skills/fresh.py`): функции `now_info()`,
   `currency_rate(code)`, `stock_quote(ticker)`; таймауты 3–5 с, кэш,
   graceful degradation (сеть упала → «не удалось получить, вот что знаю»).
2. **Роутер намерений** в `tools/chat_server.py` и `tools/chat.py`:
   регулярки/ключевые слова («который час», «сколько времени», «курс доллара»,
   «какой курс евро», «цена акции Сбер», «сколько стоит акция X»); найденное
   намерение → факт в системный/контекстный блок вида
   `[Факт: 2026-11-26 15:30 MSK, курс USD = 78.12 ₽ (ЦБ РФ)]`.
3. Модель **не должна** выдумывать: правило в промпте «если в блоке [Факт]
   есть данные — используй только их».
4. Тесты: парсеры XML/JSON на фикстурах (без сети), роутер намерений
   (20+ фраз), деградация без сети, кэш; живые прогоны — вручную.
5. Живая проверка: «который час» → текущее время; «курс доллара» → цифра ЦБ;
   «цена акции Сбер» → цифра MOEX.

## Критерии приёмки
- [ ] «который час» отвечает реальным временем (MSK)
- [ ] «курс доллара» — реальный курс ЦБ, не выдумка
- [ ] «цена акции Сбер» — реальная цена MOEX
- [ ] без сети — понятная деградация, не падение
- [ ] тесты на фикстурах, полный набор зелёный

### Как это работает

1. `POST /api/chat` → до генерации вызывается сбор фактов (`_fresh_fact`).
2. Роутер `eva/skills/intent.py::detect` решает: время / валюта / бумага и о
   чём именно. Порядок — время → бумага → валюта: «курс акций Сбера» это биржа,
   а не курс ЦБ. Длительности («сколько времени едет доставка»), каталог
   («сколько стоит тариф») и болтовня остаются модели.
3. `fresh` берёт данные (кэш → сеть) и отдаёт `Fact`; `fact_line` собирает
   строки `[Факт: … (источник: …)]`.
4. `with_fact` дописывает их в системный блок (если системного нет — создаёт
   `system`-сообщение только с фактом). В историю факт не пишется: он приходит
   в каждый запрос заново.
5. Модель по правилу промпта только формулирует ответ.

Примеры фактов:

```
[Факт: 26 ноября 2026, 15:30 MSK (источник: часы сервера)]
[Факт: 1 USD = 82,3130 ₽ (источник: ЦБ РФ на 26.11.2026)]
[Факт: SBER (Сбербанк) = 285,01 ₽, за день -2,41 ₽ (-0,84 %), закрытие вчера 287,42 ₽ (источник: MOEX ISS, 26.11.2026 15:23 MSK)]
```

`POST /api/chat` не менялся: страница и EVA.app ничего не передают. Факт
выключается `--no-facts` / `facts=False`; при `use_system=false` он не
подкладывается (колонка явно просили без системного блока).

### Замечания по интеграции (задача 0209)

В дереве параллельно живёт рантайм плагинов (0209): `plugins/time`,
`plugins/currency`, `plugins/stocks` вызывают **эти же** `fresh.now_info` /
`currency_rate` / `stock_quote`, а распознавание берут из `intent.detect`, и
именно они сейчас наполняют `[Факт]` в `tools/chat_server.py` и `tools/chat.py`.
Поэтому в `chat_server.py` пришлось поправить два места, где одноимённый
`default_registry` (реестр бэкендов) подменял фабрику реестра плагинов: без
этого `server.plugins` оказывался кортежем `BackendSpec`, и факты молча
пропадали. Если 0209 перепишет эти строки — алиас `default_plugin_registry`
надо сохранить.

### Риски и ограничения

* **MOEX в серверном пути идёт по http.** `plugins/stocks` (0209) передаёт свой
  `ctx.fetch` и при ошибке TLS повторяет запрос по `http://`, потому что
  OpenSSL из Homebrew не знает «Russian Trusted Root CA» (macOS — знает;
  Safari/curl работают). Мой `fresh._http_get` в этом случае проверку **не
  отключает**, а повторяет запрос с корнями из хранилища ОС
  (`security find-certificate -a -p`). Рекомендация: плагину использовать
  `fresh._http_get` или тот же контекст, иначе данные MOEX идут без TLS.
* **`pyexpat` на этом хосте сломан** (Python 3.14 из Homebrew): `ElementTree` и
  `minidom` падают при импорте. Поэтому XML ЦБ разбирается регулярками. Формат
  плоский и стабильный, но если ЦБ добавит вложенность или сменит кавычки —
  парсер вернёт `None` (деградация), а не мусор.
* **Курс ЦБ — дневной**, не биржевой: внутри дня он не меняется, кэш 1 ч это
  учитывает. Котировка MOEX кэшируется 60 с, поэтому в пределах минуты два
  вопроса увидят одну цену; данные TQBR — режим основных торгов, не вечерняя
  сессия.
* **Кэш общий на процесс** и не сбрасывается при смене часового пояса/даты:
  после полуночи курс ЦБ обновится только по истечении часа (до этого факт
  честно называет дату среза).
* **Правило промпта — не гарантия.** 3B может проигнорировать `[Факт]` и
  ответить по-своему (в live-прогонах не наблюдалось, но 3B есть 3B). Полной
  гарантии даёт только детерминированный ответ скилла из реестра, а он для
  сетевых данных намеренно не используется.
* **Факт удлиняет промпт** на ~60–150 символов (≈20–50 токенов) — это prefill
  и TTFT. Один факт на вид намерения; «курс валют» — три строки (USD/EUR/CNY).
* **Погода не сделана**: в задаче она опциональна, время ушло на TLS-ловушку
  MOEX и интеграцию с 0209.
