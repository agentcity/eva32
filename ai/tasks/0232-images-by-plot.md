# «Картинки вразнобой, а иногда просто скан текста»

## Жалоба (пользователь)
1. Иллюстрации подставляются не по смыслу: колобок катится, а на картинке
   печка; порядок файлов ≠ порядок сюжета.
2. Часть «иллюстраций» — сканы книжных страниц: текст без картинки или
   страница целиком.

## Задача 1 — отсеять сканы текста (данные)
1. Написать утилиту `tools/image_text_coverage.swift` (macOS, Vision:
   `VNRecognizeTextRequest`): для JPEG считает **долю площади**, занятую
   распознанным текстом, и печатает `файл<TAB>доля<TAB>строк`.
2. Прогнать по всем `plugins/fairy-tales/images/*/*.jpg`. Файлы с долей текста
   **> 12 %** — кандидаты на удаление/замену: страница с текстом, а не
   иллюстрация.
3. Заменить их лучшими PD-изображениями (Commons: категории художников, лубки,
   открытки), чтобы у каждой из 9 сказок осталось **6–10** картинок и доля
   текста ≤12 %. Если замены нет — удалить и оставить меньше, но не тащить скан
   текста.
4. В `credits.md` — отметка «проверено OCR: доля текста N %» и причина замены.

## Задача 2 — подбор по сюжету (код)
1. **Теги картинок**: `plugins/fairy-tales/images/<slug>/tags.json` —
   `{"01.jpg": {"who": ["колобок"], "what": ["катится", "дорога"], "where": ["лес"]}, …}`.
   Заполнить по метаданным Commons (название файла, описание) и по сюжету
   сказки; если картинка про «печку и стариков» — так и записать.
2. **Ключевые слова абзаца**: лемматизация простыми правилами (окончания,
   как в `_keywords`), плюс словарь персонажей (колобок, лиса, волк, медведь,
   бабка, дедка, журавль, царевна, яга…).
3. **Подбор**: для каждого абзаца — картинка с максимальным пересечением
   тегов и слов абзаца; без повторов (каждая картинка один раз); если
   пересечения нет — ближайшая по порядку из оставшихся (не «первая»).
4. `after_chars` — по-прежнему на границе абзаца, к которому подобрана.
5. Тесты: на «Колобке» картинка с тегом «катится/дорога» попадает в абзац,
   где колобок катится; ни одна картинка не используется дважды; при пустых
   тегах — порядок; скан текста (доля >12 %) в набор не попадает.

## Критерии приёмки
- [ ] у 9 сказок 6–10 картинок, доля текста ≤12 % у всех
- [ ] картинки подобраны по сюжету абзаца (видно на «Колобке» и «Репке»)
- [ ] без повторов, порядок after_chars возрастает
- [ ] `credits.md` с OCR-долей и причинами замен
- [ ] тесты и полный набор зелёные
