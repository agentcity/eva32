# Веб-адаптер: сравнение двух моделей рядом

## Проблема

Для оценки «насколько умна» нужно видеть два ответа рядом: наша тритовая
против Qwen. Скрипт этого не даёт — нужна страница.

## Требования

- `tools/chat_server.py`: минимальный сервер (stdlib, без зависимостей) на
  localhost: `GET /` — страница, `POST /api/chat` — SSE-стрим.
- Выбор двух бэкендов (vtm + ollama) и моделей; один вопрос — два ответа **рядом**,
  с временем и ток/с у каждого.
- Никаких внешних CDN: один HTML-файл со встроенным CSS/JS.
- Не слушать наружу (127.0.0.1), порт по `--port`, закрытый список бэкендов.
- Тесты: страница отдаётся, API отвечает на мок-бэкенде.

## Критерии приёмки

[ ] страница отдаётся на 127.0.0.1, два ответа рядом
[ ] SSE-стрим работает для обоих бэкендов
[ ] нет внешних запросов (проверка: в HTML нет http-ссылок)
[ ] тесты на моках

## Контекст и ограничения

- Зона определяется названием задачи и файлами, которые в ней упомянуты.
- Параллельно работают пять других агентов — чужие файлы не трогать.
- **Запрещено:** pip, сеть (кроме ollama на localhost), git-коммиты, запуск
  сервера на внешнем интерфейсе, скачивание моделей HF без явного флага.
- **Отчёт пиши первым блоком ответа** — агенты этой сессии падают на финальном шаге.
- Проверка: `python3 -m unittest discover -s tests`; где нужно — `cd src/vtm && make test`.
