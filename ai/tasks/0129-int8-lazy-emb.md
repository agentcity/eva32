# Ленивый int8-эмбеддинг

## Контекст

0044 материализует int8-тензор в fp32 в арене: +4× памяти к файлу (~233 МиБ для таблицы 1.5B). Ленивого чтения `q·scale` на лету нет.

## Требования

- чтение int8 на лету без fp32-копии;
- замер RSS на форме 1.5B (число в отчёте);
- паритет с текущим путём ≤1e-5.

## Критерии приёмки

- [ ] результат совпадает с текущим путём (допуск в отчёте)
- [ ] числа до/после (память/скорость)
- [ ] `make test` и Python-набор зелёные
