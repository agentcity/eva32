# Скиллы: расширить и измерить маршрутизацию

## Проблема

Скиллы отвечают на 24 из 60 тестовых запросов и стоят 0 ₽, но их мало и качество
маршрутизации не измеряется по классам. Это дешёвый способ поднять качество без GPU.

## Требования

- Посмотреть `eva/skills/`: какие есть, чего не хватает из реальных вопросов (погода,
  время, будильник, напоминание, перевод, математика, конвертация единиц, курс валют
  по справочнику).
- Добавить 3–5 скиллов, каждый — чистый Python без сети, с тестами.
- `tools/eval_hybrid.py`: отчёт по классам запросов (какой скилл поймал, что ушло в
  модель), чтобы видеть промахи.
- Не менять порог роутера без замера.

## Критерии приёмки

[ ] новые скиллы с тестами (>=3), каждый отвечает без модели
[ ] eval_hybrid показывает разбивку по классам и долю скиллов
[ ] маршруты 60/60 не сломаны, стоимость не выросла
[ ] полный Python-набор зелёный

## Контекст и ограничения

- Зона: eva/skills/, tools/eval_hybrid.py, tests/test_skills_*.py
- Другие файлы НЕ трогать: параллельно работают пять других агентов по своим модулям.
- **Запрещено:** запускать сервер/демон, качать модели, pip install, сеть (кроме уже
  установленных пакетов), git-коммиты.
- **Отчёт пиши первым блоком в ответе**, потом детали: агенты этой сессии падают на
  финальном шаге, отчёт первым спасает работу.
- Проверка: `python3 -m unittest discover -s tests` (сейчас 1071 тест, должно быть
  зелёным и не меньше).

## Отчёт исполнителя

Сделано: 4 новых скилла без сети — время/дата (МСК, подменяемое «сейчас»), конвертация
единиц, математика (через `ast`, без `eval`), курсы валют по встроенному справочнику с
датой среза и пометкой «не онлайн-курс». Порядок реестра сохранён: новые не отбирают
вопросы у каталожных. `eval_hybrid.py`: разбивка по классам, `skill_hits`,
`unused_skills`, промахи содержания, флаг `--min-skill-share`. 79 тестов.

Числа: маршруты 60/60 (100%), скиллы 24/60 (40,0% — **на golden новых классов нет**),
цена та же 230,15 ₽/1000. Зонд из 18 реальных вопросов новых классов: до 0/18, после
**18/18**, вызовов модели 0 (было бы ~625,80 ₽/1000 при уходе в big).

Риски: курс валют — статический срез, будет расходиться с рынком; проценты и
напоминания сознательно не перехватываются (второе — нет планировщика); часовой пояс
фиксирован МСК.
