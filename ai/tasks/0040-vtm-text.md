# ВТМ: текстовый прогон через токенизатор

## Проблема

`vtm run` принимает номера токенов. Для настоящей модели нужен путь «текст на входе →
токены → модель → текст на выходе», иначе машиной нельзя пользоваться.

## Требования

- `vtm run model.vtm --text "вопрос"`: токенизация через BPE-токенизатор (0040 зависит от
  готового `vtm-tok`; если его нет — понятная ошибка).
- `--tokenizer path` для указания tokenizer.json.
- Вывод: сгенерированный текст, а не только номера токенов.
- Не ломать существующий `--tokens`.

## Критерии приёмки

[ ] `make test` зелёный
[ ] тест: текст → токены → текст на синтетической модели (или понятная ошибка без токенизатора)
[ ] `--tokens` работает как раньше
[ ] README обновлён

## Контекст и ограничения

- Зона: src/vtm/main.c, tests/vtm/test_vtm.c (только новые тесты), src/vtm/README.md
- Другие файлы не трогать: параллельно работают другие агенты (0035 — контейнер v0.2,
  0029 — компилятор).
- Только stdlib, сеть в тестах запрещена.
- Не коммитить: сдавать правки и отчёт.
