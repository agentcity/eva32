# Q4 в компиляторе

## Проблема

Импорт GGUF (0153) пишет Q4-сегменты и манифест с `architecture.lm_head='q4'`, но
`tools/vtm_compile.py` читает только триты и падает: «допустимо tmv|mm». Без этого
7B Q4 не собрать в контейнер, хотя формат (0151) и ядра (0152) готовы.

## Требования

- `vtm_compile`: читать Q4-сегменты (`tools/vtm_ref.decode_q4_segment_ex`) →
  `Tensor` kind 5; `matrix_tensor` умеет KIND_Q4; `lm_head='q4'` (TMV по kind 5).
- Q4 TMV **transposed** пока не поддержан в ядрах — если граф требует транспонированный
  Q4, выдай внятную ошибку, а не тихий неверный счёт (это отдельная задача).
- Проверить на реальном срезе 3B из 0153: импорт → компиляция → запуск 1 токена,
  сверить с Python-эталоном (≤1e-5).
- Замер: время сборки и размер контейнера для 3B-среза и (если хватит места) полного 3B.
- Доки: `docs/vtm.md` — строка про Q4 в компиляторе.

## Критерии приёмки

- [ ] срез 3B из GGUF собирается и считает токен, паритет с Python ≤1e-5
- [ ] `lm_head='q4'` работает (TMV по kind 5)
- [ ] транспонированный Q4 даёт внятную ошибку
- [ ] тесты: манифест с Q4, отказ на неподдержанном варианте
