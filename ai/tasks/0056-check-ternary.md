# Проверка троичности

## Проблема

«Троичная модель» — утверждение, которое надо проверять, а не принимать на веру.
Нужна команда, которая читает `.trit`/`.vtm` и говорит: все ли веса в {-1, 0, +1},
какая доля нулей, какие масштабы, сколько бит на вес.

## Решение

`tools/check_ternary.py <path>`: разбирает сегменты TRT1, считает распределение
тритов, ловит значения вне множества (их не должно быть вовсе — формат хранит число
по основанию 3), печатает статистику масштабов и биты на вес с их учётом.

## Критерии приёмки

- [x] на демо-модели: вне {-1,0,+1} — 0
- [x] печатает распределение −1/0/+1 и долю нулей
- [x] считает биты на вес с масштабами
- [x] exit 1 при испорченном файле

## Отчёт исполнителя

Демо-модель (случайные веса, 155 648 тритов): вне множества 0, распределение
25,2% / 49,6% / 25,2% — симметрично, как и должно быть у случайных весов.
С учётом масштабов 1,710 бита на вес.
