# Кодовые данные

## Проблема

Для QAT было 206 пар — модель 1.5B на них переобучится и разучится отвечать.
Нужен объём (тысячи пар), на котором сравнение none/int8/trit имеет смысл.

## Решение

Программирование на русском: учитель знает тему без галлюцинаций, данные однородные,
и для эксперимента с квантованием важна не предметная область, а объём и качество.

- `distill/gen_code_questions.py` — 4 064 уникальных вопроса (Python, JS, SQL,
  алгоритмы, Git, Linux, ООП, async, тесты, безопасность) без сети.
- `distill/run.py` — добавлены `--workers`, `--resume`, `--incremental`, `--profile`,
  `--system`; запись каждой пары сразу, чтобы обрыв не терял прогресс.
- `distill/filters.py` — профиль `code`: латиница и листинги нормальны, проверяется
  русское объяснение (≥40 кириллических символов) и отсутствие внешних ссылок.
- `distill/teacher.py` — `reasoning: {enabled: false}` вместо `exclude` и
  `max_tokens` 1800. Причина: `exclude` только прячет рассуждения, но платим за них.

## Замеры

| Режим | Токенов | reasoning | ₽/пара |
|---|---|---|---|
| `exclude: true` | 695 | 101 | 0,104 |
| `effort: none` | 549 | 0 | 0,051 |
| **`enabled: false`** | 384 | **0** | **0,032** |

Плюс `max_tokens=900` обрезал ответы: рассуждения съедали 400–500 токенов, часть
ответов приходила пустой.

## Критерии приёмки

- [x] генератор даёт тысячи уникальных вопросов без сети
- [x] фильтр не режет код (было 15 из 30 отброшено, стало 3 из 20 — пустые)
- [x] цена упала в 3,3 раза при том же качестве
- [ ] дистилляция 4 064 пар завершена, файл `distill/out/code_pairs.jsonl`
