# Промпт короче: 4,4 КБ — это 1000 токенов prefill

## Проблема

Системный промпт 4,4 КБ ≈ 1000 токенов, а prefill стоит 0,073 с на токен — то есть
минута до первого слова. Сокращение промпта в 3 раза ускоряет первый ответ в 3 раза
без единой строки C-кода.

## Требования

- Проанализировать текущие `prompts/system.ru.md` и `system.code.ru.md`: что можно сжать
  без потери поведения (перевод по запросу, правила стиля, отказные сценарии).
- Цель: **<= 1500 символов** (примерно 350–400 токенов) при сохранении ключевых правил.
- Проверить на golden: маршруты и содержание не должны упасть (`tools/eval_hybrid.py`,
  `eval/hybrid_golden.jsonl`).
- Тест: промпт не длиннее лимита, обязательные правила присутствуют (перевод, отказ,
  стиль).

## Критерии приёмки

[ ] промпт <= 1500 символов, ключевые правила на месте (тест)
[ ] eval_hybrid не хуже: маршруты 80/80, содержание не упало
[ ] число токенов до/после посчитано и записано

## Контекст и ограничения

- Зона: prompts/system.ru.md, prompts/system.code.ru.md, tests/test_prompts.py
- Другие файлы НЕ трогать: параллельно работают семь других агентов по своим зонам.
  В частности `interp.c` — 0112, `backend_*.c` — 0113, `main.c/api.c/api.h` — 0114,
  `eva/server.py` — 0115, `docs/` — 0116, `tools/ci.py` — 0117, `loader.c` — 0118,
  `prompts/` — 0119.
- **Запрещено:** pip, сеть, запуск сервера на порту, git-коммиты, скачивание моделей.
- **Отчёт пиши первым блоком ответа** — агенты этой сессии падают на финальном шаге.
- Проверка: `python3 -m unittest discover -s tests` (сейчас 1517 тестов) и, где нужно,
  `cd src/vtm && make test`.
- Если нужен API из чужой зоны (например `vtm_run_batch` из 0112) — опиши контракт в
  отчёте и используй заглушку, не правь чужой файл.
