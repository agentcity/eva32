# eva: метрики и отмена запросов на сервере

## Проблема

Сервер стримит ответы (0025), но не измеряет: сколько токенов, какая задержка до
первого токена, сколько запросов отменено. Без этого нельзя понять, где голос
тормозит — в модели или в транспорте.

## Требования

- В `telemetry.py`: счётчики per-request — TTFT (время до первого чанка),总 время,
  число токенов, код завершения (ok/stop/cancel/error), маршрут (skill/small/big).
- В `server.py`: при отключении клиента (SSE-обрыв) — отмена генерации, а не
  продолжение в пустоту; счётчик отмен.
- Сводка: `GET /metrics` (JSON) — суммарные и перцентили p50/p95/p99 по TTFT.
- Тесты: фейковые часы/генератор, проверка счётчиков, отмена при обрыве.

## Критерии приёмки

[ ] /metrics отдаёт JSON со счётчиками и перцентилями (тест)
[ ] обрыв SSE отменяет генерацию и увеличивает счётчик (тест)
[ ] TTFT считается от запроса до первого чанка (тест с фейковыми часами)
[ ] полный Python-набор зелёный

## Контекст и ограничения

- Зона: eva/server.py, eva/telemetry.py, tests/test_eva_server_metrics.py
- Другие файлы НЕ трогать: параллельно работают пять других агентов по своим модулям.
- **Запрещено:** запускать сервер/демон, качать модели, pip install, сеть (кроме уже
  установленных пакетов), git-коммиты.
- **Отчёт пиши первым блоком в ответе**, потом детали: агенты этой сессии падают на
  финальном шаге, отчёт первым спасает работу.
- Проверка: `python3 -m unittest discover -s tests` (сейчас 1071 тест, должно быть
  зелёным и не меньше).
