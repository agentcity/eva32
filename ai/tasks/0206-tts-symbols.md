# Что ещё не проговаривается

## Замер (baya, /api/tts, размер WAV — короткий = знак выпал)
| текст | WAV | вывод |
|---|---|---|
| «2 × 3» | 58 844 Б | «×» и цифры теряются |
| «5 км²» | 48 044 Б | степень теряется |
| «Цена 50 €» / «50 $» | 99 644 Б | валюта выпадает |
| «Пишите на info@example.com» | 63 644 Б | email выпадает целиком |
| «Тег #маркетинг» | 98 444 Б | «#» не проговаривается |
| «И т.д. и т.п., ул. Ленина, г. Москва» | 384 044 Б | сокращения читаются по буквам |
| «8 999 123 45 67» | 542 444 Б | телефон как число, а не по цифрам |

## Требования
1. **Символы → слова** (в `eva/ru_numbers.py` или новом `eva/ru_speech.py`):
   `+` плюс, `-` минус, `×`/`*` умножить на, `÷`/`/` делить на, `=` равно,
   `<` меньше, `>` больше, `≤` не больше, `≥` не меньше, `±` плюс-минус,
   `≈` примерно, `°` градус(ов), `°C` градусов Цельсия, `²` в квадрате,
   `³` в кубе, `€` евро, `$` долларов, `£` фунтов, `₽` рублей, `%` процентов,
   `‰` промилле, `№` номер, `§` параграф, `&` и, `~` примерно, `^` в степени,
   `→` стрелка вправо (и ← ↑ ↓), `½` одна вторая, `¼` одна четвёртая,
   `¾` три четвёртых, `© ® ™` — убрать, кавычки/ёлочки — убрать,
   `— – ‒` → запятая (пауза), `…` → запятая.
2. **Сокращения**: т.д. → так далее, т.п. → тому подобное, т.е. → то есть,
   ул. → улица, г. → город, руб. → рублей, коп. → копеек, шт. → штук,
   ч. → часов, мин. → минут, тыс. → тысяч, млн → миллионов, млрд → миллиардов,
   мск → по московскому времени.
3. **Телефоны**: последовательность из 7+ цифр (возможно с +7/8, пробелами,
   скобками, дефисами) читать **по цифрам**: «восемь, девятьсот…» нет —
   «восемь девять девять девять один два три четыре пять шесть семь».
4. **Email**: `info@example.com` → «info собака example точка com» (латиницу
   можно по буквам или как есть — главное не молчать).
5. Единицы: `км²` → «километров в квадрате», `м²`, `км/ч` → «километров в час»,
   `₽/шт` → «рублей за штуку».
6. Не ломать: URL по-прежнему вырезается, код в бэктиках не трогается,
   `--prefill`-подобные токены не нормализуются.
