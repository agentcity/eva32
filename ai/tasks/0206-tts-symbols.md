## Требования
1. **Символы → слова** (в `eva/ru_numbers.py` или новом `eva/ru_speech.py`):
   `+` плюс, `-` минус, `×`/`*` умножить на, `÷`/`/` делить на, `=` равно,
   `<` меньше, `>` больше, `≤` не больше, `≥` не меньше, `±` плюс-минус,
   `≈` примерно, `°` градус(ов), `°C` градусов Цельсия, `²` в квадрате,
   `³` в кубе, `€` евро, `$` долларов, `£` фунтов, `₽` рублей, `%` процентов,
   `‰` промилле, `№` номер, `§` параграф, `&` и, `~` примерно, `^` в степени,
   `→` стрелка вправо (и ← ↑ ↓), `½` одна вторая, `¼` одна четвёртая,
   `¾` три четвёртых, `© ® ™` — убрать, кавычки/ёлочки — убрать,
   `— – ‒` → запятая (пауза), `…` → запятая.
2. **Сокращения**: т.д. → так далее, т.п. → тому подобное, т.е. → то есть,
   ул. → улица, г. → город, руб. → рублей, коп. → копеек, шт. → штук,
   ч. → часов, мин. → минут, тыс. → тысяч, млн → миллионов, млрд → миллиардов,
   мск → по московскому времени.
3. **Телефоны**: последовательность из 7+ цифр (возможно с +7/8, пробелами,
   скобками, дефисами) читать **по цифрам**: «восемь, девятьсот…» нет —
   «восемь девять девять девять один два три четыре пять шесть семь».
4. **Email**: `info@example.com` → «info собака example точка com» (латиницу
   можно по буквам или как есть — главное не молчать).
5. Единицы: `км²` → «километров в квадрате», `м²`, `км/ч` → «километров в час»,
   `₽/шт` → «рублей за штуку».
6. Не ломать: URL по-прежнему вырезается, код в бэктиках не трогается,
   `--prefill`-подобные токены не нормализуются.

### Символ → как звучит

| Символ | Речь | Пример |
| --- | --- | --- |
| `+` | плюс | `5 + 3` → «пять плюс три» |
| `-` | минус | `-5` → «минус пять» |
| `−` (U+2212) | минус | `5 − 3` → «пять минус три» |
| `×`, `*` | умножить на | `2 × 3` → «два умножить на три» |
| `÷`, `/` | делить на | `6 / 2` → «шесть делить на два» |
| `=` | равно | `2 = 2` → «два равно два» |
| `<`, `>` | меньше, больше | `5 < 7` → «пять меньше семь» |
| `≤`, `≥` | не больше, не меньше | `5 ≤ 7` → «пять не больше семь» |
| `±` | плюс-минус | `5 ± 1` → «пять плюс-минус один» |
| `≈`, `~` | примерно | `≈ 5` → «примерно пять» |
| `°` | градус/градуса/градусов (по числу) | `20°` → «двадцать градусов», `1 °C` → «один градус Цельсия» |
| `°C` | градусов Цельсия | `20°C` → «двадцать градусов Цельсия» |
| `²`, `³` | в квадрате, в кубе | `5²` → «пять в квадрате» |
| `€` | евро | `50 €` → «пятьдесят евро» |
| `$` | доллар/доллара/долларов | `1 $` → «один доллар», `50 $` → «пятьдесят долларов» |
| `£` | фунт/фунта/фунтов | `2 £` → «два фунта» |
| `₽` | рубль/рубля/рублей (0205) | `50 ₽` → «пятьдесят рублей» |
| `%` | процент/процента/процентов (0205) | `50%` → «пятьдесят процентов» |
| `‰` | промилле | `5 ‰` → «пять промилле» |
| `№` | номер | `№ 5` → «номер пять» |
| `§` | параграф | `§ 5` → «параграф пять» |
| `&` | и | `Иванов & Ко` → «Иванов и Ко» |
| `^` | в степени | `2^3` → «два в степени три» |
| `→` | стрелка вправо | `Шаг 1 → Шаг 2` → «Шаг один стрелка вправо Шаг два» |
| `← ↑ ↓` | стрелка влево/вверх/вниз | `назад ←` → «назад стрелка влево» |
| `½` | одна вторая | `½` → «одна вторая» |
| `¼`, `¾` | одна четвёртая, три четвёртых | `¾` → «три четвёртых» |
| `© ® ™` | убираются (не звучат) | `© 2026 Компания` → «две тысячи двадцать шесть Компания» |
| кавычки `« » „ “ ” ‹ › "` | убираются | `«Привет», мир!` → «Привет, мир!» |
| `— – ‒` | запятая (пауза) | `Москва — столица` → «Москва, столица» |
| `…` | запятая | `Подождите…` → «Подождите,» |
| `#` | хештег (перед словом) / решётка | `#маркетинг` → «хештег маркетинг» |
| `/` между словами | «или» для «и/или», иначе пробел | `и/или` → «и или», `операций/с` → «операций с» |

### Сокращения

| Вход | Речь |
| --- | --- |
| `т.д.` / `т.п.` / `т.е.` | так далее / тому подобное / то есть |
| `ул.` / `г.` / `мск` | улица / город (`2026 г.` → «года») / по московскому времени |
| `руб.` / `коп.` | рублей / копеек — с согласованием: `2 руб.` → «два рубля», `5 коп.` → «пять копеек» |
| `шт.` / `ч.` / `мин.` | штук / часов / минут: `2 шт.` → «две штуки», `5 ч.` → «пять часов», `30 мин.` → «тридцать минут» |
| `тыс.` / `млн` / `млрд` | тысяч / миллионов / миллиардов: `15 тыс.` → «пятнадцать тысяч», `2 млн` → «два миллиона» |

Без числа — множественная форма (`шт.` → «штук», `тыс. руб.` → «тысяч
рублей»); «1 500 шт.» распознаётся как разряды, а не как число 1500:
«тысяча пятьсот штук».

### Риски и оговорки

1. **`#` через `/api/tts` не звучит** — `clean_tts_text` в
   `tools/chat_server.py` (вне зоны) заменяет `#` пробелом до нормализации.
   Прямой путь говорит «хештег тег»; в HTTP-пути — тишина, как и раньше.
   Лечится правкой порядка чистки в сервере (не делал: файл вне зоны).
2. **Телефон vs разряды.** Эвристика: 7+ цифр, ≥2 разделителя (или `+` и 10+
   цифр), и не «все группы после первой по три цифры». Поэтому `8 999 123 456`
   (все группы по 3) читается как число, а `1 500 000` — как разряды.
   Для номеров в такой записи правило надо будет уточнить (например, по
   префиксу 7/8 и длине 11 цифр).
3. **Дефис между числами остался диапазоном** (`10-20`, `10 - 20` → «от
   десяти до двадцати», как в 0205). «Минус» — это `-5`/`(−5)` и знак
   `−` U+2212; `5 - 3` без минус-знака читается как диапазон. Так сохраняется
   поведение 0205 для цен («1000 - 2000 ₽»).
4. **`г.` после года** — «года» («2026 г.» → «две тысячи двадцать шесть
   года»), иначе «город». Идеальнее «2026 год», но это уже морфология
   порядковых (вне задачи).
5. **Стрелки** читаются буквально по ТЗ: «стрелка вправо». Для навигации,
   возможно, лучше «далее» — одна правка в словаре `_WORD_SYMBOLS`.
6. **Единицы без числа** не согласуются: `5 кг` → «пять кг» (кг не было в
   списке сокращений задачи), `шт.` → «штук». С числом — согласуются
   (`2 шт.` → «две штуки»).
7. **Нормализация меняет смысл знаков, которые люди пишут как тире**: `-`
   между словами с пробелами → запятая («Москва - столица»), дефис внутри
   слова не трогается («по-русски»).
8. **Замеры зависят от движка и голоса**: цифры сняты на этом Mac, Silero v4_ru
   `baya`, 48 кГц. На `say`/ElevenLabs абсолютные байты будут другими, но
   нормализация общая — меняется только звук, не текст.
