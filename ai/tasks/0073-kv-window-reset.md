# KV: окно и сброс

## Проблема

`KVW` при позиции >= ctx возвращает ошибку: диалог длиннее 2048 токенов просто
ломается. Между запросами KV не сбрасывается одним вызовом — второй запрос
продолжает первый.

Вынесено из задачи 0065: агент дважды падал на ней, `eps` закрыт архитектором.

## Требования

- `context_window` в мете: при переполнении — сдвиг окна (ротация K/V), а не отказ;
  позиции для ROPE остаются корректными.
- `vtm_reset(m)` сбрасывает KV, счётчики и сэмплер; ответ после reset совпадает с
  ответом свежей машины.
- Тест: 2×ctx токенов без ошибки; последние токены не теряются.

## Критерии приёмки

- [ ] генерация 2×ctx токенов не падает и не теряет хвост
- [ ] после `vtm_reset` ответ побитово совпадает со свежей машиной
- [ ] `make test` и полный Python-набор зелёные

## Контекст и ограничения

- Зона: `src/vtm/interp.c` (KVW/ATTN), `src/vtm/vtm.h`, `src/vtm/vtm_internal.h`,
  `tests/vtm/test_vtm.c`.
- Делать, когда освободится `interp.c` (сейчас там идёт 0065-переделка и 0068).
