# Бандл EVA32

## Проблема

Модель заявлена, но не воспроизводима: нет зафиксированного промпта, конфига
генерации, проверок и способа поднять сервер.

## Требования

- Системный промпт с правилами и примерами, версионируемый вместе с конфигом.
- Конфиг генерации и serving (vLLM) с закреплённой ревизией модели.
- Набор поведенческих проверок и раннер, считающий результат по bundle-хешу.
- Makefile-цели для локальной проверки без GPU.

## Критерии приёмки

- [x] `prompts/system.ru.md`, `config/generation.yaml`, `serving/compose.yaml` в репозитории
- [x] `eval/run_eval.py` считает поведенческие проверки и пишет JSON с bundle-хешем
- [x] `make eval-dev` прогоняет набор на локальной модели
- [x] Ревизия базовой модели закреплена в `.env.example` и MODEL_CARD

## Отчёт исполнителя

Сделано в серии коммитов до 2026-11-18. Промпт v2 (20/34 на qwen2.5:3b),
eval с поведенческими проверками, Makefile, NOTICE, закреплённая ревизия.
