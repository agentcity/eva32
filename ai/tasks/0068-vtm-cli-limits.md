# Волна 1: CLI — текстовые стопы, лимиты, таймаут

## Проблема

В CLI есть только стоп-токен из словаря. Нельзя сказать «остановись после пустой
строки», нельзя ограничить время, нельзя задать бюджет токенов для голоса.

## Требования

- `--stop "текст"` (можно несколько): остановка, когда декодированный текст
  заканчивается на эту строку; строка не попадает в вывод.
- `--max-tokens N` (уже есть --max-new — проверить, что это оно) и `--timeout SEC`:
  по таймауту генерация завершается, код 124, всё сгенерированное печатается.
- `--stats` — в stderr: токенов, время, токенов/с, пик RSS (если просто).
- Без новых флагов поведение прежнее.

## Критерии приёмки

[ ] `--stop "\n\n"` останавливает и не печатает стоп-строку (тест)
[ ] `--timeout 0.01` завершает генерацию с кодом 124, вывод не теряется
[ ] `--stats` печатает число токенов и токенов/с в stderr
[ ] make test, make test-all зелёные

## Контекст и ограничения

- Зона: src/vtm/main.c, tests/vtm/test_vtm.c
- Другие файлы НЕ трогать: параллельно работают семь других агентов по строго
  разным файлам. Пересечение зон запрещено.
- Сборка: `cd src/vtm && make test`; `-Wall -Wextra -Werror`.
- Не менять поведение без новых флагов.
- Не коммитить: сдавать правки и отчёт.

## Отчёт исполнителя

Сделано: `--stop` (повторяемый, escape-последовательности, придержка хвоста в
потоке с выравниванием по границе UTF-8), `--timeout` (код 124, сгенерированное не
теряется), `--stats` (токены, время, токенов/с в stderr), `--max-tokens` как синоним
`--max-new`.

Проверено: `make test`, `make test-all` (131) и полный набор 1044 теста зелёные;
`--stats` печатает `токенов=2, время=0.001227 с, токенов/с=1629.99`.

Оговорка из проверки: таймаут проверяется между токенами, поэтому на demo-модели
раньше срабатывает ограничение ctx=8 (KVW) — это ровно то, что закрывает задача 0073.
Ограничения записаны: --stop сравнивает побайтово, без Unicode-нормализации; один
долгий vtm_run не прерывается.
