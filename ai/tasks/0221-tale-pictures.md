# Сказка с картинками

## Зачем
Ребёнку читать сказку без картинок — половина удовольствия. Нужно: Ева
рассказывает и **показывает иллюстрацию по сюжету** (в чате и в приложении).

## Источник картинок — общественное достояние
Классические иллюстрации к русским сказкам **уже нарисованы** и свободны:
И. Билибин (Василиса Прекрасная, Царевна-лягушка, Перышко Финиста, Сестрица
Алёнушка), А. Куркин, Б. Зворыкин, В. Васнецов. Брать с Wikimedia Commons
(`commons.wikimedia.org/w/api.php`, `prop=imageinfo&iiprop=url&iiurlwidth=1024`),
сохранять локально — офлайн, как и текст.

**Генерацию не делаем**: локальная SD на 16 ГиБ — это минуты на картинку и
непредсказуемое качество; классические иллюстрации лучше и бесплатны.

## Контракт (расширение `answer`)
Плагин может вернуть не только строку, но и словарь:

```python
{"text": "Слушай сказку…", "images": [
    {"path": "images/kolobok/01.jpg", "alt": "Колобок катится по дорожке",
     "after_chars": 320}, …]}
```

`path` — относительно каталога плагина (`plugins/fairy-tales/`),
`after_chars` — на каком символе текста показать картинку.

## Требования
1. **Картинки**: для 6–10 самых известных сказок скачать 2–4 иллюстрации
   (PD) в `plugins/fairy-tales/images/<slug>/NN.jpg`, ширина ~1024 px, JPEG
   ≤ 300 КБ каждая. Рядом `credits.md` (автор, источник, лицензия).
   Остальные сказки — без картинок (не блокер).
2. **Плагин**: `answer` возвращает словарь с `images` (см. контракт), разбивая
   текст на части по `after_chars`; без картинок — прежняя строка.
3. **Сервер** (`tools/chat_server.py`):
   - если плагин вернул изображения — отдавать их в SSE отдельным событием
     `{"type": "image", "side": N, "url": "/media/fairy-tales/<slug>/01.jpg",
     "alt": "…"}` **между** delta-кусками по `after_chars`;
   - эндпоинт `GET /media/<plugin>/<path>` — отдаёт файл ТОЛЬКО из
     `plugins/<id>/images/` (проверка канонического пути, никаких `..`),
     Content-Type по расширению, кэш `Cache-Control: max-age=86400`;
   - без картинок поведение не меняется.
4. **Тесты**: контракт `answer`-словаря, порядок image-событий относительно
   delta, `/media` отдаёт картинку и **отказывает** на `../`, на чужой плагин,
   на не-изображение; плагин возвращает словарь только когда картинки есть.
5. **Живой прогон**: «расскажи сказку про колобка» → в SSE есть `image`
   события, `/media/...` отдаёт JPEG (проверить `file`), размеры вменяемые.

## Критерии приёмки

- [ ] SSE: image-события идут по ходу текста
- [ ] `/media` безопасен (нет выхода за каталог, нет чужих файлов)

- [ ] тесты и полный набор зелёные
