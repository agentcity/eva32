# Сказка на ночь по просьбе

## Задача
«Расскажи сказку», «сказку про лису», «сказку на ночь» → Ева **рассказывает
сказку целиком**, голосом (Silero baya), без участия модели.

## Что уже есть
В рантайме плагинов появилась способность **`answer`**: `plugins/<id>/plugin.py`
объявляет `capability: ["answer"]` и функцию `answer(ctx, question) -> str |
None`. Сервер (`tools/chat_server.py::_run_side`) вызывает такие плагины ДО
модели и, если пришёл текст, отдаёт его как ответ с `finish_reason="plugin"`
(модель не участвует).

## Требования
1. **Корпус офлайн** `plugins/fairy-tales/tales/*.md` — 6–10 русских народных
   сказок в общественном достоянии (Колобок, Репка, Теремок, Курочка Ряба,
   Лиса и журавль, Маша и медведь, Три медведя, Заюшкина избушка, Вершки и
   корешки, Петушок и бобовое зёрнышко). Источник текста — Викитека
   (`ru.wikisource.org`, API) или другой свободный; сохранить в репозиторий,
   чтобы работало без сети. В манифесте каждой сказки — title, tags (лиса,
   медведь, зима, короткая), возраст.
2. **Плагин** `plugins/fairy-tales/`:
   - `answer(ctx, question)`: распознаёт просьбу («расскажи сказку», «сказка
     про лису», «на ночь», «про колобка»); выбирает сказку по тегу/названию;
     без указания — случайную короткую; возвращает текст для чтения вслух;
   - `skill.fetch` НЕ нужен — только `answer`;
   - дружелюбное начало: «Слушай сказку…», конец: «Сказке конец, а кто слушал —
     молодец» (или мягкая концовка на ночь);
   - если сказок нет/не распознал — `None` (пусть отвечает модель).
3. **Для озвучки**: текст без markdown, короткие абзацы, числа в словах
   (`eva.ru_numbers`); сервер сам режет на куски ≤600 символов (уже умеет).
4. **Команды**: «следующая сказка» (продолжить репертуар) — через состояние
   плагина (последняя сказка), «хватит» — сервер уже обрабатывает как стоп.
5. Тесты `tests/test_fairy_tales.py`: распознавание 10+ фраз, выбор по тегу,
   случайная без параметра, отсутствие сказок → None, текст без markdown,
   `answer` подключён к реестру (capability).
6. Проверка живьём: сервер, «расскажи сказку про лису» → ответ плагина
   (`finish_reason=plugin`), и `/api/tts` озвучивает первые 600 символов.

## Отчёт исполнителя

Сделано:

- корпус `plugins/fairy-tales/tales/*.md` — 9 сказок в общественном достоянии:
  «Колобок», «Репка», «Теремок», «Курочка Ряба», «Лиса и журавль»,
  «Вершки и корешки», «Три медведя», «Кот, петух и лиса», «Зимовье зверей».
  У каждой — `title`, `tags`, `age`, `source` (ссылка на Викитеку); тексты
  скачаны один раз, рантайм в сеть не ходит;
- `plugin.json` — `capabilities: ["answer"]`, `permissions.network: []`,
  `permissions.filesystem: ["tales"]`, `priority: 20`;
- `plugin.py` — распознавание просьбы, выбор по тегу/названию (грубое
  сравнение корней: «лису» → «лиса», «колобка» → «колобок»), случайная
  короткая сказка без параметра, «следующая сказка» по состоянию плагина,
  `None` для чужих тем. Текст без markdown, числа через
  `eva.ru_numbers.numbers_to_words`, абзацы ≤ 480 символов, начало
  «Слушай сказку…», концовка «Сказке конец…» или мягкая «Сладких снов»;
- `config/plugins.json` — плагин включён; `tests/test_plugins.py` — id добавлен
  в ожидаемый набор (правка вне основной зоны, иначе старый тест падал);
- `tests/test_fairy_tales.py` — 15 тестов: 14 фраз распознавания, отрицания,
  выбор по тегу, «следующая»/заворот, ночной режим, пустой корпус → `None`,
  отсутствие цифр/markdown, числа словами, capability в
  `default_registry().answers()`;
- `docs/plugins.md` — раздел «Сказки: плагин `fairy-tales`».

Проверка живьём (сервер 8765; 0.5b указана в первой колонке, вторая
выключена):

- `POST /api/chat` «расскажи сказку про лису» → `finish_reason="plugin"`,
  `source="plugin"`, 7 мс, ответ 1290 символов, «Лиса и журавль»; модель не
  загружалась (`/api/models`: `loaded=false`, `requests=0`) — генерации не было;
- «следующая сказка» → «Репка»; «сказка на ночь» → концовка «Сладких снов»;
  «расскажи сказку про колобка» → «Колобок»;
- `POST /api/tts` на первые 595 символов (по границе слова) → WAV
  4 020 044 байта, 48 кГц mono, 41,88 с (Silero `baya`) — озвучка работает.

Тесты: `python3 -m unittest discover -s tests -q` — 2876 тестов, OK
(73 skipped); отдельно `tests.test_plugins`, `tests.test_fairy_tales`,
`tests.test_music_control` — 93 теста, OK.

Риски: состояние «последней сказки» общее на процесс (два диалога делят
репертуар; после рестарта сбрасывается); выбор без параметра случайный;
некоторые варианты Афанасьева архаичны и местами жестоки (лиса съедает
колобка/петуха) — возраст в шапке ориентировочный; при повторной закачке
Викитека отдаёт 429 без паузы между запросами.
