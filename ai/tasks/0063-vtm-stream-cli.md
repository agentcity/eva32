# Стриминг из CLI и безопасный UTF-8

## Проблема

`vtm run` печатает ответ только целиком. Для голоса и SSE нужен токен по мере
готовности. Плюс декодирование по одному токену может разрезать русскую букву:
UTF-8 символ занимает 2 байта, а BPE-токенов у него может быть два.

## Требования

- `--stream`: печатать текст по мере генерации (stdout, без буферизации строки).
- Безопасный декодировщик: накапливать байты, отдавать только завершённые UTF-8
  символы; недописанный хвост держать до следующего токена.
- Спецтокены (`<|im_end|>` и пр.) не печатать в тексте, обрывать генерацию по
  стоп-токену.
- Без `--stream` поведение прежнее.

## Критерии приёмки

[ ] `--stream` печатает по токену и не режет русские буквы (тест на «привет»)
[ ] при обрыве на середине символа хвост не теряется (тест)
[ ] генерация останавливается на `<|im_end|>` (тест)
[ ] `make test`, `make test-all` зелёные

## Контекст и ограничения

- Зона: src/vtm/main.c, src/vtm/tokenizer.hpp, src/vtm/tokenizer.cpp (только decode), tests/vtm/test_vtm.c (новые тесты в конце), docs/vtm.md (раздел CLI)
- Другие файлы НЕ трогать: параллельно работают другие агенты (0059 — interp.c,
  0060 — loader.c, 0063 — main.c/tokenizer). Пересечение зон запрещено.
- Сборка: `cd src/vtm && make test`; флаги `-Wall -Wextra -Werror`.
- Не менять поведение без новых флагов.
- Не коммитить: сдавать правки и отчёт.

## Отчёт исполнителя

Сделано: `--stream` (stdout только текст, служебное в stderr), `DecoderStream`
с накоплением недописанных UTF-8 байт, стоп-токены из `model.eos_token` и special
added_tokens, спецтокены не печатаются.

Проверено архитектором: `make test` и `make test-all` зелёные, полный набор 920
тестов зелёный. Доказательство по байтам: «п» приходит как два токена (208, 191), в
stdout уходит ровно `D0 BF`; обрыв на середине символа даёт `EF BF BD` и остановку
на стоп-токене; ресинхронизация не выпускает сырой `D0`.

Ограничения: стоп-множество — эвристика по именам спецтокенов; недописанный хвост в
конце становится U+FFFD; в потоковом режиме печатаются только special added_tokens.
