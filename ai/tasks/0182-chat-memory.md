# Чат не помнит предыдущие сообщения

## Проблема
`chat_server` собирает запрос как `[system, user]` — **истории нет**. Каждый вопрос
задаётся с чистого листа: модель не видит, о чём говорили раньше.

## Требования
1. **История на колонку**: сервер хранит последовательность `user`/`assistant`
   отдельно для левой и правой колонки; в запрос уходит `[system, ...история, user]`.
   Ответ дописывается в историю после `done`.
2. **Обрезка по бюджету**: лимит `--history-tokens` (по умолчанию 1024, 0 — без
   истории) и максимум реплик (`--history-turns`, по умолчанию 8). Обрезаем самые
   старые пары целиком, системный промпт не теряем. Если бюджет считается по
   символам (токенизатора под рукой нет) — оценка ~3 символа на токен и честная
   пометка «оценка».
3. **UI**: в шапке колонки — «история: N реплик · ~M токенов»; кнопка
   **«Новый диалог»** (сбрасывает историю колонки). При ошибке генерации история
   не растёт (не записываем пустой ответ).
4. **API**: `POST /api/reset` (сброс истории колонки/обеих), поле `history` в
   `/api/models` или отдельный `/api/history`.
5. **Честность**: в `delta`/`done` не менять формат; историю не подмешивать в
   системный промпт.

## Критерии приёмки
- [ ] второй вопрос видит первый (проверить: «меня зовут Юра» → «как меня зовут?»)
- [ ] обрезка работает (история не растёт бесконечно), системный промпт на месте
- [ ] «Новый диалог» очищает, 0 отключает историю
- [ ] тесты на моках, полный набор зелёный
