# Смешанная точность: FFN в тритах, чувствительное — в int8/fp16

## Проблема

Наивная третизация всех Linear даёт ×7,3e5 PPL. Но слои не равны: attention
чувствительнее к ошибкам, FFN избыточнее и это 2/3 параметров. Гипотеза: если оставить
эмбеддинг+lm_head в int8, attention в int8/fp16, а третить только gate/up/down,
текст может остаться читаемым при файле в 2–2,5 раза меньше fp16.

## Требования

- Новый `tools/export_mixed.py` (не правь `cold_export.py`): экспорт с по-слойной
  точностью по политике `--policy ffn-trit|attn-int8|embed-int8|...`, комбинации.
- Собрать 4–6 конфигураций на Qwen 0.5B, померить PPL (`tools/parity_cold.py`) и
  декодировать 2 ответа на каждую.
- Таблица: конфигурация → размер файла → PPL → ×bf16 → читаемо/нет.
- Найти лучшую конфигурацию и оценить размер той же схемы для 3B (аналитически).

## Критерии приёмки

[ ] ≥4 конфигурации измерены (PPL + размер + декод)
[ ] названа лучшая и её режим отказа
[ ] аналитическая оценка размера для 3B
