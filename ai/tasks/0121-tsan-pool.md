# ThreadSanitizer для пула

## Проблема

Задача 0113 переписала пул потоков: горячий путь без мьютекса (слот команды на поток,
release/gen, монотонный done), динамическая раздача строк порциями; барьер подешевел с
4,95 до 1,10 мкс, 8 потоков перестали быть медленнее 4 (+57%).

При этом там же **найдены и исправлены два редких дедлока** (чтение общих параметров
не-участником, потерянное пробуждение). 240 последовательных и 30 параллельных прогонов
на форме 1.5B зависаний не дали — но **TSan не запускался**, а lock-free код без
санитайзера это лотерея.

## Требования

- Прогнать `make test` и бенчмарк под `-fsanitize=thread` (CFLAGS/LDFLAGS через make).
- Разобрать все отчёты: либо исправить, либо задокументировать как ложные с обоснованием.
- Добавить шаг `make tsan` (или в `tools/ci.py`) — хотя бы необязательный, с таймаутом.
- Проверить гонки в: слоте команды, `done`-счётчике, пуле (создание/уничтожение),
  `vtm_threads_set`.

## Критерии приёмки

## Отчёт исполнителя

Сделано: цель `make tsan` (`TSAN_FLAGS=-fsanitize=thread -g -O1`, пер-бинарный
таймаут, `TSAN_RUN=` отключает, `-Werror` снят только в TSan-сборке) и новый
`tests/vtm/tsan_pool.c` (1..8 потоков, n=1/2/3, **4 одновременных отправителя**,
`vtm_threads_set` параллельно, пробуждение после 200 мс, 4 потока в `tmv_lut`).

**Найдено три дефекта, все реальные (ложных 0):**
1. **Нет сериализации отправителей.** Два потока одновременно проходили
   `wait_prev_done()`, публиковали один `gen`, затирали `total/chunk/cmd` и уводили
   `workers_left` в underflow. Следствие — **use-after-free**: воркер чужого задания
   писал в уже `free()`-буфер. Исправлено мьютексом на всё задание.
2. Гонка `g_cfg_override` (`vtm_threads_set` против `vtm_parallel_rows`) — атомарные
   load/store.
3. Гонка `lut_ready`/LUT243 при одновременных `tmv_lut` — `pthread_once`.

**Проверено:** `make tsan` — **0 отчётов**, exit 0 (86 с на этой машине, 37 с в
изолированной копии); `make test` — exit 0, 1734 Python-теста OK. На HEAD новый тест
даёт **9 отчётов и дедлок** — то есть тест реально ловит то, что чинили.

Цена решения: мьютекс на задание — барьер `bench --pool` 1,20 → 1,25 мкс (в шуме);
конкурирующие отправители теперь ждут друг друга (так и должен вести себя контракт).
Ограничения: нет symbolizer (в отчётах адреса без file:line), TSan и UBSan вместе
нельзя, уничтожения пула в API нет (воркеры detached до конца процесса).
