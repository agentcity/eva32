# Волна 4: случайный паритет C↔Python

## Проблема

Паритет проверен на фиксированных конфигурациях. Случайные архитектуры
(разные heads/kv_heads/head_dim/слои/vocab/rope) не проверялись — а именно там
прячутся ошибки индексации GQA и заголовков.

## Требования

- `tools/parity_random.py`: генерирует N случайных конфигураций (hidden 64..256,
  heads 1..8, kv_heads 1..heads, head_dim 8..64, слоёв 1..3, vocab 32..512,
  rope_theta 1e4..1e6, tied/untied), строит контейнер через `tools/vtm_compile.py`,
  гоняет C (`vtm run`) и Python-эталон (`vtm_ref.execute`), сравнивает логиты.
- Фиксированный seed; `--count`, `--tolerance` (по умолчанию 1e-5).
- Печатает худшее расхождение и конфигурацию, где оно встретилось.
- Тесты: генератор конфигураций детерминирован, сравнение и отчёт — без запуска C.

## Критерии приёмки

[ ] 50 конфигураций: max|Δ| < 1e-5, ни одного расхождения argmax (числа в отчёте)
[ ] при расхождении печатается конфигурация для воспроизведения
[ ] тесты без сети и без C зелёные
[ ] если найдены расхождения — заведены задачи с параметрами

## Контекст и ограничения

- Зона: tools/parity_random.py, tests/test_parity_random.py
- Другие файлы НЕ трогать: параллельно работают семь других агентов.
- `src/vtm/*` не править (там 0065/0067), `loader.c` не править (0066).
- Не коммитить: сдавать правки и отчёт.

## Отчёт исполнителя

Сделано: `tools/parity_random.py` (50 случайных архитектур, воспроизводимых по
seed+index) и 54 теста без C.

Проверено архитектором своим прогоном: 50/50 прошли, **max|Δ| = 0.000e+00**
(бит-в-бит), расхождений argmax нет, вердикт PASS. Покрытие: блоки 128/160,
tied/untied, kv_heads < heads, heads 1..8, head_dim 8..62, vocab 41..504,
theta 12,6e3..905e3, слои 1..3, rope half/interleaved.

Негативный контроль у исполнителя: порча 20 float в строке эмбеддинга даёт
max|Δ| = 3,1e-05 → FAIL. То есть сравнение ловит расхождение, а не сравнивает
вектор сам с собой.

Ограничения записаны: блок 160 проверен только по модели в памяти (Python-эталон
читает с диска 128); не покрыты bias, fp16-масштабы, тритовые эмбеддинги, контекст
>8, eps≠1e-3.
