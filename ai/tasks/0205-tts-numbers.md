# «Цена 1500 рублей» → тишина

## Симптом (замерено)
| текст | размер WAV |
|---|---|
| «Цена одна тысяча пятьсот рублей» | **201 644 Б** |
| «Цена 1500 рублей» | **76 844 Б** ← втрое короче |
| «Скидка 20 процентов» | 127 244 Б (частично) |

Silero v4_ru **не произносит цифры** (пропускает токен-число), поэтому в ответах
пропадают цены, сроки, проценты — самое важное для бизнес-ассистента.

## Требования
1. **Нормализация чисел в русские слова** перед синтезом (`eva/tts.py`,
   общий `_clean_text`/новый модуль `eva/ru_numbers.py`):
   - целые: 0…10^12 (1500 → «тысяча пятьсот», 2000 → «две тысячи»,
     25000 → «двадцать пять тысяч», 1000000 → «миллион»);
   - дробные: «1,5» / «1.5» → «одна целая пять десятых» (или «полтора», если 1,5);
   - знаки: «₽»/«руб.» → «рублей», «%» → «процентов», «№» → «номер»,
     «+7» в телефоне → «плюс семь»;
   - диапазоны «10-20» → «от десяти до двадцати»;
   - даты «01.02.2026» → «первое февраля две тысячи двадцать шесть»;
   - не трогать числа внутри кода/URL (URL и так вырезается).
2. Работает для всех движков (Silero, ElevenLabs, say) — нормализация до выбора
   движка, а не внутри Silero.
3. Тесты: слова для 0/1/2/5/11/21/100/101/1000/1500/2000/25000/1000000/1,5/1.5;
   интеграция: `/api/tts` «Цена 1500 рублей» даёт WAV **≥** как у словесной формы
   (проверка, что числа реально звучат).
4. Не ломать существующие тесты TTS; число в тексте не должно съедать соседние
   пробелы/пунктуацию.

## Критерии приёмки
- [ ] «Цена 1500 рублей» синтезируется не короче словесной формы
- [ ] тесты чисел и грамматики (тысяча/тысячи/тысяч, миллион/миллиона/миллионов)
- [ ] все движки получают нормализованный текст
- [ ] полный набор зелёный
