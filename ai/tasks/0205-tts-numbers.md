# «Цена 1500 рублей» → тишина

## Симптом (замерено)
| текст | размер WAV |
|---|---|
| «Цена одна тысяча пятьсот рублей» | **201 644 Б** |
| «Цена 1500 рублей» | **76 844 Б** ← втрое короче |
| «Скидка 20 процентов» | 127 244 Б (частично) |

Silero v4_ru **не произносит цифры** (пропускает токен-число), поэтому в ответах
пропадают цены, сроки, проценты — самое важное для бизнес-ассистента.

## Требования
1. **Нормализация чисел в русские слова** перед синтезом (`eva/tts.py`,
   общий `_clean_text`/новый модуль `eva/ru_numbers.py`):
   - целые: 0…10^12 (1500 → «тысяча пятьсот», 2000 → «две тысячи»,
     25000 → «двадцать пять тысяч», 1000000 → «миллион»);
   - дробные: «1,5» / «1.5» → «одна целая пять десятых» (или «полтора», если 1,5);
   - знаки: «₽»/«руб.» → «рублей», «%» → «процентов», «№» → «номер»,
     «+7» в телефоне → «плюс семь»;
   - диапазоны «10-20» → «от десяти до двадцати»;
   - даты «01.02.2026» → «первое февраля две тысячи двадцать шесть»;
   - не трогать числа внутри кода/URL (URL и так вырезается).
2. Работает для всех движков (Silero, ElevenLabs, say) — нормализация до выбора
   движка, а не внутри Silero.
3. Тесты: слова для 0/1/2/5/11/21/100/101/1000/1500/2000/25000/1000000/1,5/1.5;
   интеграция: `/api/tts` «Цена 1500 рублей» даёт WAV **≥** как у словесной формы
   (проверка, что числа реально звучат).
4. Не ломать существующие тесты TTS; число в тексте не должно съедать соседние
   пробелы/пунктуацию.

## Критерии приёмки
- [ ] «Цена 1500 рублей» синтезируется не короче словесной формы
- [ ] тесты чисел и грамматики (тысяча/тысячи/тысяч, миллион/миллиона/миллионов)
- [ ] все движки получают нормализованный текст
- [ ] полный набор зелёный

## Отчёт исполнителя

**Статус: сделано.** Числа превращаются в русские слова **до выбора
TTS-движка**, поэтому Silero/ElevenLabs/`say` получают уже слова. Живьём:
«Цена 1500 рублей» — WAV **171 644 Б** вместо **76 844 Б** до фикса (×2,23),
и байт-в-байт совпадает с WAV той словесной формы, в которую текст теперь
нормализуется.

### Примеры преобразований

| Вход | Выход |
| --- | --- |
| `Цена 1500 рублей` | `Цена тысяча пятьсот рублей` |
| `2000`, `25000` | `две тысячи`, `двадцать пять тысяч` |
| `1000000`, `2000000` | `миллион`, `два миллиона` |

| `1,5` и `1.5` | `одна целая пять десятых` |
| `1500 ₽`, `1500 руб.`, `1500 р.` | `тысяча пятьсот рублей` |
| `№ 5` | `номер пять` |
| `10-20`, `от 5 до 10` | `от десяти до двадцати`, `от пяти до десяти` |
| `10-20%` | `от десяти до двадцати процентов` |

### Замер WAV (Silero v4_ru, baya, 48 кГц)

«До» воспроизведено независимо — сырой текст через `tools/silero_speak.py`
(без нормализации); «после» — свежий `tools/chat_server.py` на 127.0.0.1
и `POST /api/tts`.

| Текст | До фикса | После `/api/tts` |
| --- | ---: | ---: |
| `Цена 1500 рублей` | 76 844 Б | **171 644 Б** |
| `Цена одна тысяча пятьсот рублей` | 201 644 Б | 201 644 Б |
| `Цена тысяча пятьсот рублей` | — | 171 644 Б (байт-в-байт как у цифр) |
| `Скидка 20 процентов` | 127 244 Б | 169 244 Б |
| `Скидка 20%` | — | 169 244 Б |
| `Абонемент 25000 рублей` | — | 225 644 Б |
| `Срок 01.02.2026` | — | 296 444 Б |

Числа и их словесная форма теперь дают **один и тот же WAV** (общий кэш
Silero): цифры в ответе больше не выпадают. `say` на тех же двух фразах
отдаёт идентичные 56 666 Б — нормализация общая, не внутри Silero.

**Нюанс критерия «не короче словесной формы»:** по требованию
`1500 → «тысяча пятьсот»` (без «одна»), поэтому 171 644 Б против 201 644 Б
у фразы с «одна» — разница ровно в одно слово. Если нужен буквальный
`>=` именно к 201 644 Б, это одна правка: в `cardinal_words` для чанка
тысяч `1` выдавать `одна тысяча` вместо `тысяча` (сейчас — как в задании).

### Риски и ограничения

1. **Падежи предложения не склоняются.** `в 2026 году` → `в две тысячи
   двадцать шесть году` (речь понятна, грамматика — нет); `5-й` →
   `пять-й`, `12:30` → `двенадцать:тридцать`. Даты и диапазоны — с
   правильным падежом там, где он заложен.
2. **Числа >10¹² и «слипшиеся» с кириллицей** (`цена1500`) остаются
   цифрами — для Silero это тишина. Редко, но лучше знать: правило «не
   трогать латиницу/код» намеренно консервативно.
3. **Двузначный год** (`01.02.26`) не нормализуется: отличать от версии
   `1.2.99` без контекста нельзя.
4. **Разряды через пробел** (`1 500` → 1500) — эвристика: список «5 100»
   может слипнуться в 5100.
5. **Серверный лимит 600 символов** считается до нормализации; после неё
   фраза длиннее (числа разворачиваются), Silero синтезирует дольше, но
   ошибки нет.
6. **Кэш и ключи** ElevenLabs/Silero теперь строятся по нормализованному
   тексту: «1500» и «тысяча пятьсот» — одна запись кэша (это плюс).
7. На 127.0.0.1:8765 работает **старый** процесс `chat_server.py` (не мой,
   не трогал): чтобы фикс заработал там, сервер нужно перезапустить.
