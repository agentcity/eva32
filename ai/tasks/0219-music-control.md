# Музыка голосом, как у Алисы

## Задача
«Включи музыку», «включи группу Кино», «следующая», «пауза», «громче»,
«выключи музыку» → Ева управляет воспроизведением на Mac и отвечает коротко.

## Что уже есть
Способность **`answer`** в плагинах (0218): `plugins/<id>/plugin.py` объявляет
`capability: ["answer"]` и `answer(ctx, question) -> str | None`; сервер зовёт
до модели и, если есть текст, не генерирует.

## Требования
1. **Плагин** `plugins/music/` с `capability: ["answer"]` (и `permissions`:
   `filesystem` — только музыкальные каталоги, если нужны; сеть — только если
   радио).
2. **Управление Music.app на macOS** через `osascript` (без сторонних API):
   - play/pause/next/previous, громкость ±10, mute;
   - поиск и запуск: `tell application "Music" to play (first track whose name contains "Кино")` —
     аккуратно: сначала плейлист/исполнитель, потом трек; при отсутствии —
     честное «не нашла в библиотеке»;
   - сейчас играет → «Играет: <исполнитель> — <название>».
3. **Интернет-радио** (если время): публичные потоки (например Radio Record,
   Европа Плюс) через `afplay`/`AVPlayer` — только прямые URL, без ключей.
   Отметить в docs, какие станции зашиты.
4. **Распознавание**: «включи музыку», «включи что-нибудь», «включи Кино»,
   «поставь джаз», «пауза», «продолжи», «следующая», «предыдущая», «громче»,
   «тише», «выключи музыку», «что играет» — 20+ фраз, с отказом на
   «включи свет» (не наша зона → None).
5. **Короткий ответ** (1 предложение) + `speak` через TTS.
6. Тесты `tests/test_music_control.py`: распознавание фраз, маппинг в
   AppleScript (мок subprocess), отказы, «не нашла трек», отсутствие Music.app.
7. Живая проверка на этой машине: `osascript` доступен; проверить, что
   команда реально управляет (или честно отчитаться, что Music.app закрыт).

## Критерии приёмки
- [ ] 20+ фраз распознаются, чужие — нет
- [ ] AppleScript-команды корректны (мок-тесты), без инъекций (экранирование)
- [ ] «включи Кино» ищет в библиотеке, при отсутствии — честный ответ
- [ ] «пауза/громче/тише/выключи» работают
- [ ] тесты и полный набор зелёные
