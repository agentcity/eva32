# «Колобо́к» вместо «Ко́лобок»

## Проблема
Silero ставит ударения по общим правилам и ошибается на сказочных словах и
именах: Ко́лобок/Колобо́к, Жу́равль/Жура́вль, Теремо́к/Тере́мок, Алёнушка,
Ива́н-царе́вич, Ба́ба-Яга́, Си́вка-Бу́рка, Хавро́шечка, Ку́рочка Ря́ба.

## Что известно
Silero (v4_ru) понимает **знак ударения `+` перед ударной гласной**:
`"Колоб+ок"` → Колобо́к, `"Терем+ок"` → Теремо́к. Наш worker передаёт текст
как есть — значит достаточно расставить `+` перед синтезом.

## Требования
1. **Словарь ударений** `eva/ru_stress.py`: `apply_stress(text) -> str`.
   - База: сказочные/частые слова с ударением (`Колоб+ок`, `Терем+ок`,
     `Жур+авль`, `Ал+ёнушка`, `Ив+ан-цар+евич`, `Б+аба-Яг+а`, `С+ивка-Б+урка`,
     `Хавр+ошечка`, `Ряб+а`, `Мор+озко`, `Снег+урочка`, `Цар+евна`,
     `Бил+ин`, `Афан+асьев` — расширить по частым ошибкам);
   - регистр сохраняется, словоформы (`Колобка` → `Колобк+а`): простое правило
     — основа + окончание, словарь хранит «основа|ударный слог»;
   - идемпотентно: уже размеченные `+` не дублируются;
   - слова короче 2 букв и код/URL не трогаются.
2. **Применение только для озвучки**: в `eva/tts.py` перед синтезом
   (Silero-движок), НЕ в тексте ответа — пользователь видит обычный текст.
3. **Флаг** `EVA_STRESS=0` — отключает (A/B и откат).
4. **Словарь можно расширять**: файл `data/stress.txt` (слово<TAB>разметка),
   читается при старте, кэшируется; понятная ошибка на битую строку.
5. Тесты: 40+ слов (включая словоформы), идемпотентность, регистр, код/URL,
   `EVA_STRESS=0`, интеграция с `normalize_tts_text` (в синтез уходит `+`).
6. Живая проверка: `/api/tts` «Колобок и Теремок» — сравнить длительность с
   размеченным вариантом (не должна отличаться радикально), и убедиться, что
   в ответе чата `+` НЕ появляется.

## Критерии приёмки
- [ ] словарь ≥40 слов, словоформы работают
- [ ] `+` не виден пользователю (только в синтезе)
- [ ] откат `EVA_STRESS=0`
- [ ] тесты и полный набор зелёные
