# RAG: контекст каталога в промпт

Контракт — `docs/hybrid.md`, решение — `docs/adr/0009-hybrid-router.md`.

## Проблема

Малая и большая модель отвечают без фактов, если их не передать. Скиллы закрывают только
прямые вопросы; на «а что входит в Профи» модель должна видеть каталог.

## Требования

- `eva/rag.py`: `retrieve(text, catalog, k=3) -> RagContext` (текст `[1] …`, источники, id позиций).
- Поиск без сети и без эмбеддингов: нормализация, синонимы, пересечение слов, вес по полю.
- `router.answer` подмешивает контекст в сообщения для small и big (только если он непустой),
  исходный запрос пользователя не меняется.
- Если контекста нет — сообщения как раньше, ничего не ломается.

## Критерии приёмки

[ ] `python3 -m unittest tests.test_rag -v` зелёный без сети
[ ] «что входит в тариф Профи» → контекст с лимитами, в ответе видно источник
[ ] вопрос вне каталога → пустой контекст, модель получает только вопрос
[ ] `tools/eval_hybrid.py` не сломан (маршруты те же)

## Контекст и ограничения

- Зона: eva/rag.py, eva/router.py (только вставка контекста), tests/test_rag.py
- Другие файлы не трогать: параллельно работают другие агенты.
- Только stdlib, без сети в тестах, без установки пакетов.
- Не коммитить: сдавать правки и отчёт.
