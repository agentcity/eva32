# Сервер: токен, лимиты и защита от злоупотреблений

Контракт — `docs/hybrid.md`, спеки — `docs/vtm.md`, ADR в `docs/adr/`.

## Проблема

Сервер слушает localhost без аутентификации. Выставить наружу нельзя: любой, кто
достучался, тратит наш бюджет на большие модели.

## Требования

- `EVA_AUTH_TOKEN`: если задан — требовать `Authorization: Bearer`, иначе 401 с JSON.
- Лимит запросов на ключ: N в минуту (configurable), 429 с `Retry-After`.
- Ограничение размера тела уже есть (1 МиБ) — проверить и не сломать.
- Без токена поведение прежнее (localhost-режим), но в лог пишется предупреждение.

## Критерии приёмки

[ ] тесты: 401 без токена, 200 с токеном, 429 после лимита
[ ] существующие тесты сервера не сломаны
[ ] runbook описывает оба режима
[ ] `python3 -m unittest discover -s tests` зелёный

## Контекст и ограничения

- Зона: eva/server.py, eva/config.py, tests/test_server.py (только новые тесты), docs/hybrid-runbook.md (раздел auth)
- Другие файлы не трогать: параллельно работают другие агенты.
- Только stdlib; сеть в тестах запрещена (кроме живого замера 0031, и то по флагу).
- Не коммитить: сдавать правки и отчёт.
