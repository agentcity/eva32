# Ответ не влезает, think не спрятан

## Проблема
1. Ответ (256 токенов) не влезает в поле — обрезается по высоте, читать неудобно.
2. Qwen3 (30B) выдаёт `<think>…</think>` — рассуждение идёт вперемешку с ответом и
   занимает экран. В DSH оно свёрнуто и раскрывается по клику.

## Требования
- Поле ответа: авто-высота по содержимому (без жёсткого max-height) или кнопка
  «развернуть/свернуть»; при генерации — авто-скролл к последнему тексту.
- `<think>`: парсить поток `delta`; текст внутри `think` уходит в отдельный
  `<details>`-блок «рассуждение (N симв.)», свёрнутый по умолчанию; теги в ответ не
  попадают. Обработать незакрытый think (поток оборвался) — весь остаток считать
  рассуждением.
- Работает и при стриминге (текст приходит кусками, тег может прийти разорванным).
- CSS/JS — внутри страницы, без внешних CDN; CSP не ослаблять.

## Критерии приёмки
- [ ] длинный ответ виден целиком (без обрезки)
- [ ] think свёрнут, раскрывается по клику, в ответ не попадает
- [ ] разорванный тег между кусками обрабатывается
- [ ] тесты chat_server зелёные, JS проходит `node --check`
