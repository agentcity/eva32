# Чат говорит вслух

## Что уже есть
`eva/tts.py` — адаптер синтеза: Piper (если установлен) → системный `say` (macOS)
→ `espeak` (Linux) → пустой движок. Контракт `synthesize(text) -> bytes | Path`.
Проверено: `say -o out.wav --data-format=LEI16@22050 "…"` даёт корректный RIFF/WAVE,
который браузер проигрывает без конвертации.

## Требования
1. **Серверный endpoint** `POST /api/tts` `{text, voice?}` → `audio/wav`
   (Content-Type `audio/wav`, `Cache-Control: no-store`). Текст чистится: без
   markdown-разметки, без `<think>…</think>`, без URL и лишних пробелов; лимит
   длины (например 600 символов) → 400 с понятным текстом.
2. **Клиент**: галочка «озвучивать» у колонки; ответ **разбивается на фразы**
   по `. ! ? …` и переводам строк, каждая фраза синтезируется сразу по мере
   прихода текста и ставится в очередь воспроизведения (первая — как пришла,
   не ждём конца ответа).
3. **Управление**: «стоп» останавливает и речь, и генерацию; новый вопрос
   очищает очередь; конец ответа — доигрывает остаток.
4. **Деградация**: если TTS недоступен (нет `say`/`piper`), галочка показывает
   «голос недоступен» и чат работает как раньше.
5. Не ломать стриминг: текст печатается независимо от аудио.

## Критерии приёмки
- [ ] `/api/tts` возвращает WAV (проверить RIFF-заголовок) и чистит разметку
- [ ] галочка озвучивает ответ по фразам, первая фраза — без ожидания конца
- [ ] стоп/новый вопрос корректно глушат звук
- [ ] без TTS — понятное сообщение, чат работает
- [ ] тесты на моках, полный набор зелёный, JS `node --check`
