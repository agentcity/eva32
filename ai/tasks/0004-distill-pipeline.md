# Конвейер сбора пар «вопрос → ответ» и оценка стоимости

## Проблема

Для дистилляции нужны пары, на которых можно учиться: с контекстом продукта,
без выдуманных цен и без чужих вендоров в ответе.

## Требования

- `distill/`: вопросы с контекстом → учитель (OpenAI-совместимый) → фильтры → дедуп → JSONL.
- Фильтры: выдуманная цена (сверка с числами контекста), иероглифы и длинная латиница,
  длина, чужой вендор, пустой вопрос.
- Системный промпт Евы в запросе — иначе учитель не ставит ссылки `[n]`.
- Учёт токенов и рублей (API возвращает `cost_rub`).

## Критерии приёмки

[x] `make test` — 60 тестов зелёные
[x] Прогон 243 вопроса: 206 пар, 99% со ссылкой, 2,08 ₽
[x] `make distill-mock` работает без сети и ключей
[x] Цена пилота 10 тыс пар ≈ 113 ₽ посчитана по факту

## Контекст и ограничения

Ключ учителя — в `.env` (в `.gitignore`), не в переписке и не в коде.
