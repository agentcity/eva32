# Слишком быстро для ребёнка

## Проблема
Ева читает сказку в темпе обычного ответа: фразы идут встык, между абзацами
паузы нет. Ребёнок не успевает следить.

## Требования (приложение, macOS)
1. **Пауза между фразами** в озвучке: после каждой воспроизведённой фразы —
   тишина, по умолчанию 350 мс; после абзаца (`\n\n`) — 900 мс.
2. **Режим сказки**: если ответ — от плагина сказок (в ответе есть картинки
   или сервер пометил источник `plugin`), паузы умножаются на 1,5–2
   (≈600 мс / 1500 мс) — «сказка читается медленнее».
3. **Настройка** в окне настроек: «Скорость чтения сказок» — «обычная» /
   «медленная» (по умолчанию «медленная»), сохраняется в UserDefaults
   (`eva.talePace`), применяется без перезапуска.
4. **Не ломать обычный чат**: короткие ответы читаются как раньше (пауза
   между фразами меньше, режим сказки не включается).
5. **Стоп/новый вопрос** — пауза прерывается немедленно.
6. Самотест `--selftest-pauses`: расчёт паузы по тексту (конец фразы, абзац,
   режим сказки), прерывание стопом, отсутствие пауз при выключенной озвучке.

## Критерии приёмки
- [ ] между фразами слышимая пауза, между абзацами — заметно длиннее
- [ ] режим сказки включается автоматически и усиливает паузы
- [ ] настройка «медленная/обычная» работает без перезапуска
- [ ] стоп прерывает паузу сразу
- [ ] сборка и самотесты зелёные
