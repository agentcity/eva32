# «Не могу предоставить курс» — при курсе в контексте

## Симптом (живой ответ)
> «К сожалению, я не могу предоставить актуальный курс доллара без возможности
> получения этой информации в реальном времени.
> [Факт: 1 USD = 82,3130 ₽ (источник: ЦБ РФ на 26.11.2026)]»

Две ошибки сразу:
1. Модель **отрицает** факт, хотя он в промпте (3B не связывает блок и вопрос).
2. Служебная строка **утекает в ответ** — пользователь видит `[Факт: …]`.

## Требования
1. **Формулировка блока**: не «[Факт: …]», а отдельная секция с явной командой:
   ```
   СПРАВКА (используй эти данные дословно; не говори, что данных нет;
   не цитируй слово «СПРАВКА»):
   Курс USD = 82,3130 ₽ (ЦБ РФ, 26.11.2026)
   ```
2. **Правило в промпте**: если есть СПРАВКА и вопрос про эти данные — ответ
   начинается с цифры, без оговорок «нет доступа/не могу».
3. **Пост-фильтр** (плагин или ядро): вырезать из ответа любые `[Факт: …]`,
   «СПРАВКА:», «(источник: …)» — пользователь не должен видеть служебное.
4. **Страж противоречия**: если в ответе есть отказ («не могу предоставить»,
   «нет доступа к», «не имею информации о курсе/цене»), а факт есть —
   заменить ответ на короткую фактическую формулировку из справки
   (детерминированно, без второго прогона модели).
5. Тесты: справка в промпте, вырезание служебного, страж (отказ+факт → факт),
   не ломать случаи без факта (обычный «не знаю» остаётся как есть).

## Критерии приёмки
- [x] «курс доллара» → ответ содержит 82,3130 ₽ и НЕ содержит «не могу» и «[Факт»
- [x] «цена акции Сбер» → цена без служебных скобок
- [x] без фактов «не могу» разрешено (не подменяем)
- [x] тесты и полный набор зелёные

### Границы решения

* Страж смотрит только начало ответа (первое предложение или 80 символов):
  отменить уже отправленные в поток символы нельзя, а держать весь ответ —
  значит убить стриминг. Отказ, пришедший после первого предложения, остаётся
  (тест это фиксирует).
* Деградация («не удалось получить…») фразой не считается: подменять отказ
  нечем, поэтому честное «не удалось» остаётся.
* Пост-фильтр вырезает и осмысленное «(источник: …)» в обычном тексте — так
  требует задача: пользователь не должен видеть служебный формат.
