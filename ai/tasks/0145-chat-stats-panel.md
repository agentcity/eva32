# Панель метрик под чатом

## Проблема

Сейчас `tools/chat_server.py` показывает ответы и ток/с в шапке колонки. Для
сравнения моделей этого мало: непонятно, **сколько модель занимает на диске**, сколько
памяти съедает при загрузке, сколько жрёт CPU и где узкое место — загрузка, prefill
или декод.

## Требования

**1. Карточка модели** (по каждому бэкенду/модели): размер файла на диске, число
параметров, контекст, размер KV-кэша, тип хранения (trit/int8/fp16-эмбеддинг),
источник (демо / холодный экспорт / QAT), словарь, число слоёв, бит на параметр.

**2. Память:** RSS процесса после загрузки модели и пик; для VTM — дельта RSS
`chat_server` до/после загрузки (модель живёт в этом же процессе через ctypes);
для ollama — из `GET /api/ps` (`size`, `size_vram`) и/или RSS процесса.

**3. Время и нагрузка:** TTFT, время prefill, время декода, ток/с декода, общее время,
CPU-время процесса за запрос (`resource.getrusage` / `time.process_time`), число потоков
VTM (`VTM_THREADS`), загрузка системы (load average, свободная RAM, свободный диск).

**4. Per-ответ:** prompt-токены, completion-токены, попал ли в кэш префикса
(для VTM), причина остановки (EOS/лимит), маркер «холодный/тёплый» первый токен.

**5. UI:** панель **под** чатом: два столбца метрик (по модели) + строка системы.
Обновление после каждого ответа, без внешних CDN, только 127.0.0.1.

## Критерии приёмки

- [ ] `GET /api/models` отдаёт карточки (размер, параметры, KV, тип, источник)
- [ ] `GET /api/system` отдаёт load, RAM, диск, CPU
- [ ] после ответа панель показывает TTFT / prefill / декод / ток/с / RSS-дельту
- [ ] значения проверяемы: размер файла == `stat`, RSS-дельта > 0 для VTM
- [ ] тесты на моках, полный набор зелёный

## Контекст

- Не трогать `tools/chat.py`, `eva/*`, `src/vtm/*`.
