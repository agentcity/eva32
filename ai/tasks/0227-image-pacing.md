# Сказка читается — картинки стоят

## Проблема
Ответ плагина приходит ОДНИМ куском: все `delta` и все `image`-события
прилетают за миллисекунды. Приложение показывает картинку сразу по событию,
поэтому видна только последняя — «картинка не меняется, пока читается».

## Требования
1. **Привязка к речи, а не к приходу текста**: очередь картинок с их
   `after_chars`; показ следующей — когда озвучка доходит до этого места.
   Опора — прогресс воспроизведения `VoicePlayer` (сколько символов уже
   сказано; сейчас там есть только уровень громкости — добавь счётчик
   сказанных символов по завершённым фразам + дробную оценку текущей).
2. **Если озвучка выключена** (или ответ `silent`, играет запись) — темп
   оценочный: ~14–16 символов в секунду (русская речь baya), с таймером;
   при `silent` (внешняя запись) картинки тоже меняются по этому темпу.
3. **Ручное управление**: картинка меняется и по концу фразы — не «залипает»,
   если речь быстрее/медленнее.
4. **Отмена/новый вопрос**: таймеры гасятся, очередь картинок очищается.
5. **Кроссфейд** (0,35 с) сохраняется; последняя картинка остаётся.
6. Самотест `--selftest-images`: сценарий «3 картинки, речь 0,5/2,5/4 с» —
   показываются последовательно, без обрыва; проверка, что смена идёт по
   прогрессу, а не по приходу событий.

## Критерии приёмки
- [ ] во время чтения сказки картинки сменяются одна за другой
- [ ] смена не быстрее речи и не «залипает»
- [ ] выключенная озвучка / silent — темп по таймеру
- [ ] новый вопрос очищает очередь
- [ ] сборка и самотесты зелёные
