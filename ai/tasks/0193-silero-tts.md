# Живой голос без облака

## Зачем
Piper разборчив, но звучит механически. ElevenLabs даёт качество, но платный и
уводит текст в облако (пользователь отказался). Silero — русская нейросеть,
локально, бесплатно, MIT/CC.

## Установка (в vendor/, в git не попадает)
1. `python3.13 -m pip install --target vendor/torch-py torch` (вендорный torch,
   колёса для cp313 macOS arm64). Проверить `import torch` **только из этого каталога**
   (в `.pylibs` лежит сломанный source-checkout — не использовать!).
2. Скачать модель Silero: `torch.hub.load('snakers4/silero-models','silero_tts',
   language='ru', speaker='v4_ru', trust_repo=True)` (первый раз нужна сеть),
   кэш положить в `vendor/silero/` (`TORCH_HOME`), чтобы дальнейшие запуски офлайн.
3. Скрипт установки `tools/install_silero.sh` (идемпотентный, как `install_piper.sh`):
   проверяет python3.13, ставит torch, качает модель, делает пробный синтез
   «Проверка голоса», печатает размеры и время.

## Код
1. `eva/tts.py`: адаптер `SileroTTS` (по образцу PiperTTS):
   - поиск: `SILERO_PYTHON` (по умолчанию python3.13 с PYTHONPATH=vendor/torch-py),
     `SILERO_MODEL_DIR` (vendor/silero), динамический импорт torch только внутри;
   - синтез: 48 кГц, `speaker` из `SILERO_SPEAKER` (по умолчанию `baya` или `xenia`
     — выбрать по замеру/прослушиванию), `sample_rate=48000`, WAV байты;
   - **питч/темп-пресеты не применять** (они были для Piper).
2. Порядок выбора: `EVA_TTS` → ElevenLabs (если ключ) → **Silero (если установлен)**
   → Piper → say → null. Аргумент: локальное лучше облака по умолчанию.
3. Нет torch/модели → откат на Piper с логом (не падать).
4. Первый синтез в процессе прогревает модель ~1–2 с — замерить и закэшировать
   в `describe()`/логах; повторные фразы должны быть быстрыми (<0,5 с на короткую).

## Критерии приёмки
- [ ] `synthesize()` даёт WAV 48 кГц, играется в чате и EVA.app (клиент уже умеет)
- [ ] время: короткая фраза <1 с (после прогрева), память процесса +~300 МБ
- [ ] без установки — Piper (как сейчас), тесты зелёные
- [ ] тест с моком torch (без реальной модели) на откат и выбор движка
- [ ] `sh tools/install_silero.sh` воспроизводим, размеры/время печатает

## Отчёт исполнителя

Сделано (зона соблюдена; `apps/eva/*`, `src/vtm/*`, `tools/chat_server.py` не
трогались):

- `tools/install_silero.sh` — идемпотентный установщик: проверяет python3.13,
  ставит `torch`+`numpy`+`omegaconf` в `vendor/torch-py`, качает модель
  `v4_ru` через `torch.hub` в `vendor/silero` (`TORCH_HOME`), синтезирует
  «Проверка голоса», печатает JSON-замеры и размеры. Повторный запуск не
  качает заново и не ломает установку.
- `tools/silero_speak.py` — одноразовый синтезатор: текст из stdin, WAV в
  argv[1], `--speaker`/`--sample-rate`, модель `v4_ru`, 48 кГц, PCM16 mono;
  `torch` импортируется только здесь (из `PYTHONPATH=vendor/torch-py`).
- `eva/tts.py` — `SileroTTS` + `find_silero_python/torch_dir/model_dir`,
  `silero_help`, LRU-кэш повторных фраз, `PYTHONPATH`/`TORCH_HOME` в
  дочернем процессе, замер холодного старта в лог/`describe()`. Пич-пресеты
  Piper не применяются: для Silero `synthesize_audio()` отдаёт
  `audio/wav; engine=silero`, поэтому `default_tts_speech` не делает
  питч-шифт (HTTP-слой по-прежнему отдаёт `audio/wav` по сигнатуре).
- `select_engine`: `EVA_TTS` → ElevenLabs (ключ) → **Silero (установлен)** →
  Piper → system → null. Нет torch/модели — автовыбор уходит на Piper
  (однократный info-лог), процесс Silero упал — откат на Piper/system с
  warning-логом, без падения.
- `tests/test_tts_silero.py` — 23 теста на моках `subprocess.Popen`: порядок
  выбора, откаты, отсутствие torch/модели, ошибки/таймаут, кэш, окружение,
  голоса. Реальный torch/модель в тестах не вызываются.
- `docs/hybrid.md` — раздел «Silero»: установка, голоса, время/память,
  приватность, переменные, откат, проверка. `README.md` — `install_silero.sh`,
  `EVA_TTS`, авто-порядок движков.
- `samples/voice_silero.wav` — образец `baya`, 48 кГц.

Интеграция: `chat_server.default_tts_speech(..., voice='young')` вернул
WAV 48 кГц без питч-шифта (`audio/wav; engine=silero` → `looks_like_audio` =
`audio/wav`).

Тесты: `tests.test_tts_silero` (23), `tests.test_tts` (23),
`tests.test_tts_elevenlabs` (46), `tests.test_chat_server` (122) — **215 OK**;
`tests.test_docs_fresh` — 33 OK. Полный `unittest discover -s tests` был
остановлен: он завис на внешних/живых тестах, не связанных с TTS.

Риски:

- **Холодный старт на каждую новую фразу 2,5–4 с**, а не <1 с: процесс
  одноразовый (torch + модель грузятся заново). Кэш спасает только повтор
  той же фразы. Для задержки <1 с нужен долгоживущий worker-процесс
  (модель загружается один раз; текст/WAV — по протоколу) — это следующий
  шаг, в текущей задаче выбран процесс-per-фраза, как у Piper.
- **Память ≈550–790 МБ на процесс**, не +300 МБ, как ожидалось. Процесс чата
  не растёт, но два параллельных синтеза (чат режет ответ на фразы) могут
  занять ~1,1–1,6 ГБ. На 16 ГБ это терпимо; на слабой машине — риск OOM.
- Установка занимает ~780 МБ диска и требует macOS arm64 + python3.13;
  на Linux/другой платформе нужны свои колёса torch.
- Модель и код `snakers4/silero-models` качаются с GitHub/`models.silero.ai`
  при установке (`trust_repo=True`); для воспроизводимости стоит закрепить
  ревизию/хэш весов. Синтез после установки офлайн.
- Голос `baya` выбран по F0/длительности и описанию, **на слух не
  прослушивался** (нет аудиовыхода у агента); при другом вкусе —
  `SILERO_SPEAKER=kseniya|xenia|aidar`.
- Изолированный `env` без `SILERO_*` намеренно не подхватывает вендорный
  Silero (защита старых тестов/встраивания); боевой путь `os.environ`
  подхватывает.
- `audio/wav; engine=silero` — совместимый маркер для `chat_server`;
  сторонний клиент, сравнивающий content-type строкой, должен использовать
  `startswith("audio/wav")`. HTTP-слой определяет MIME по сигнатуре.
