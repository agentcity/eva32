# Данные: разбиение train/val и предтокенизация для QAT

## Проблема

Для обучения нужны train/val без утечки (вопросы уникальны, но похожие формулировки
могут попасть в обе части) и заранее посчитанные токены, чтобы считать шаги и
эффективность до аренды GPU. Сейчас этого нет: есть только сырой jsonl.

## Требования

- `tools/prepare_qat_data.py`: читает `distill/out/code_pairs.jsonl`, чистит,
  разбивает 90/10 с замороженным seed, пишет `data/train.jsonl`, `data/val.jsonl`.
- Дедупликация по нормализованному вопросу (нижний регистр, пунктуация) и проверка
  пересечения train/val = 0.
- Предтокенизация через существующий BPE-токенизатор (`tokenizer.json`, из 0012):
  посчитать токены, распределение длин (p50/p95/max), сколько пар длиннее контекста
  (2048) — это станет «обрезано/отброшено».
- Отчёт в JSON: `data/stats.json` (число пар, токенов, распределение, оценка шагов при
  batch 4 и 2).
- Тесты: разбиение детерминировано, пересечения нет, обрезка считается верно.

## Критерии приёмки

[ ] train/val 90/10, пересечение 0 (тест)
[ ] stats.json с распределением длин и оценкой шагов
[ ] сколько пар длиннее 2048 — число в отчёте
[ ] полный Python-набор зелёный

## Контекст и ограничения

- Зона: tools/prepare_qat_data.py, tests/test_prepare_qat_data.py, distill/
- Другие файлы НЕ трогать: параллельно работают пять других агентов по своим модулям.
- **Запрещено:** запускать сервер/демон, качать модели, pip install, сеть (кроме уже
  установленных пакетов), git-коммиты.
- **Отчёт пиши первым блоком в ответе**, потом детали: агенты этой сессии падают на
  финальном шаге, отчёт первым спасает работу.
- Проверка: `python3 -m unittest discover -s tests` (сейчас 1071 тест, должно быть
  зелёным и не меньше).
