# «Включи запись сказки» — с живой интонацией

## Зачем
Синтез не передаёт интонацию, а актёрская запись — передаёт. Там, где есть
**свободная** запись, лучше включить её, чем читать.

## Требования
1. **Поиск записей**: Wikimedia Commons (audio + PD/CC), Archive.org (только
   явная лицензия CC0/CC-BY/PD — фильтровать по `licenseurl`, НЕ брать
   «все права защищены»). Сохранять локально в
   `plugins/fairy-tales/audio/<slug>.ogg` (или .mp3), ≤3 МБ на сказку.
   В `audio/credits.md` — автор, источник, лицензия.
2. **Начать с малого**: 3–5 записей (например «Сказка о царе Салтане»,
   народные сказки в исполнении чтецов), остальные — без записи.
3. **Плагин**: команда «включи запись сказки», «поставь аудиосказку»,
   «сказку в исполнении» → `answer` возвращает текст-подтверждение и
   побочное действие: запуск `afplay` (список argv, без shell) с локальным
   файлом; «стоп»/«выключи» — terminate процесса.
4. **Если записи нет** — честно: «Записи этой сказки у меня нет, могу
   рассказать сама» и НЕ падать.
5. **Сервер/приложение**: воспроизведение идёт на Mac (afplay), поэтому
   приложение просто получает подтверждение; голосовая озвучка ответа не
   нужна (иначе будет говорить поверх записи) — вернуть признак
   `{"text": ..., "silent": true}`, сервер не шлёт `/api/tts` для такого ответа.
6. Тесты: распознавание фраз, запуск/остановка (мок subprocess), отсутствие
   записи, `silent` доходит до клиента, лицензии в credits.
7. Живая проверка: «включи запись сказки» → процесс afplay запущен (проверить
   `pgrep afplay`), затем «выключи» → процесс живёт/умер, ответ корректен.
   Если песочница не даёт звук — отметьте честно, важен факт запуска.

## Критерии приёмки
- [ ] 3–5 записей CC/PD с credits
- [ ] «включи запись сказки» запускает локальный файл
- [ ] «выключи»/«стоп» останавливает
- [ ] нет записи → честный ответ, без падения
- [ ] `silent` не даёт двойной озвучки
- [ ] тесты и полный набор зелёные
