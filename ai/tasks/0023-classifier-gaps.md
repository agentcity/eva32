# Промахи классификатора

## Проблема

Замер гибрида (`python3 tools/eval_hybrid.py`) даёт 94% точности маршрутов. Все три
промаха — big→small, то есть сложный вопрос ушёл в дешёвую модель:

1. «Придумай план запуска продукта за 30 дней» — нет маркера «придумай».
2. «Напиши SQL-запрос: топ-10 клиентов по выручке» — «напиши» есть, но SQL не распознан.
3. «Какая столица Австралии?» — вопрос на общие знания, без маркеров.

## Требования

- Добавить маркеры творческих/структурных задач: «придумай», «составь», «спланируй»,
  «sql», «запрос», «формул», «таблиц», «схем».
- Распознавать вопросы на общие знания: «столица», «сколько будет», «кто такой»,
  «в каком году», «переведи на» — это big, потому что скиллов и каталога там нет.
- Не сломать обратное: «сколько стоит тариф Старт» обязан остаться skill.
- Пороги и маркеры — по-прежнему из конфига, не хардкодом.

## Критерии приёмки

- [ ] Точность маршрутов на `eval/hybrid_golden.jsonl` ≥ 96% (было 94%)
- [ ] Ни один промах не стал скиллом там, где скилла нет
- [ ] `python3 -m unittest discover -s tests` зелёный
- [ ] В отчёте — таблица «вопрос → было → стало»

## Контекст и ограничения

- Зона: `eva/classifier.py`, `tests/test_classifier.py`, `eval/hybrid_golden.jsonl`
  (только добавление строк, не правка ожиданий под ответ).
- Не подгонять набор под код: если пример размечен неверно — обосновать и исправить
  ожидание отдельной строкой в отчёте.
