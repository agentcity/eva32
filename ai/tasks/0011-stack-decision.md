# Выбор стека

## Проблема

Начали на C99 + Python. Нужно решить обоснованно: остаётся ли C, стоит ли C++ или Go,
и не разъедется ли стек по слоям.

## Требования

- Решение по каждому слою отдельно, с критериями: SIMD, контроль памяти, экосистема,
  скорость разработки, безопасность.
- Явно указать, что делать с уже начатым кодом.
- Зафиксировать, при каких условиях решение пересматривается.

## Критерии приёмки

- [x] Таблица «слой → язык → почему не иначе»
- [x] Разбор Go и C++ по фактам, а не по вкусу
- [x] Указано, что происходит с задачами 0002/0003/0006
- [x] Записано, когда пересматривать (Rust, если начнём с нуля; Go, когда дойдём до сервиса)

## Контекст и ограничения

- Код в работе не выбрасываем: C-ядра остаются, C++ добавляется сверху.
- Никаких новых зависимостей в рантайме.

## Отчёт исполнителя

Написан `docs/stack.md`: C99 — ядра по C-ABI, C++17 — интерпретатор, KV, токенизатор;
Python — обучение, данные, компилятор; Go — только сервисный слой позже.
Go отклонён для ВТМ по трём причинам: нет интринсиков, GC в горячем цикле, нет
ML-экосистемы. Rust отклонён как добавляющий недели без выигрыша в скорости.
