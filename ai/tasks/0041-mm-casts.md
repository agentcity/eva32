# MM и большие размерности

## Проблема

Задача 0035 нашла: в `src/vtm/interp.c` проверка формы MM сравнивала размерности
через `(uint16_t)`, поэтому C отвергал матрицы с ведущей размерностью >65 535,
хотя Python считал их корректно. Для Qwen это блокер: tied lm_head считается как
`MM A=[151936,hidden] · B=[hidden,1]`.

## Требования

- Заменить касты `uint16_t` на `uint32_t` в проверке формы MM.
- Обновить `src/vtm/README.md`: там всё ещё описан v0.1 (44 байта, dims u16).

## Критерии приёмки

- [x] MM с `A=[151936,1]·B=[1,1]` не отвергается
- [x] `make test` в src/vtm зелёный
- [x] README описывает v0.2 (52 байта, dims u32)

## Контекст и ограничения

- Зона: `src/vtm/interp.c`, `src/vtm/README.md`.
- Не менять семантику MM — только проверку формы.

## Отчёт исполнителя

Касты заменены, сборка проверена. README приведён к v0.2.
