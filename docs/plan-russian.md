# План: Ева должна хорошо понимать русский

Состояние на 2026-11-18. Версия бандла `1.0.1`, хеш `8cfb1835f514`.

## Что значит «хорошо понимает русский»

Пять вещей, и каждая должна быть измерима, иначе это разговор о вкусе:

1. **Понимает смысл** — включая опечатки, транслит, разговорные формулировки, многозначность.
2. **Отвечает по-русски** — без английских и китайских вставок (у нас это уже ловилось: «全额退款»).
3. **Грамотно** — согласование, падежи, числа, единицы.
4. **Уместно** — деловой тон без канцелярита, кратко.
5. **Честно** — отказ и «не нашла» тоже по-русски, а не «I can't».

## Что есть сейчас

- 34 строки золотого набора, из них про язык — 2 (`lang-ru`, `lang-en-question`). Этого мало: мы меряем правила, а не язык.
- Базовые числа на стенде: qwen2.5:3b — 20/34, 7b — 5/8 на старом наборе. DeepSeek V4-Flash на русском **не измерялся вообще** — это главный пробел.
- Промпт требует русский (правило 1), но проверка ловит только наличие латиницы, а не грамматику.

## Фаза 1. Измерить, а не предполагать (3–4 дня, 0 ₽)

- [ ] **Токенизация**: сколько токенов уходит на типичный русский вопрос против английского. Это прямая цена: если русский «дороже» на 30%, это 30% к счёту за диалог.
- [ ] **Код-свитчинг**: доля ответов с иноязычными вставками на 100 запросах. Сейчас измеряется только в одной строке.
- [ ] **Слепой срез 50 ответов** на живые вопросы → ручная оценка по шкале 1–5 (понятность, грамматика, тон). Два разметчика, расхождение > 1 балла разбираем.
- [ ] **Базовая линия DeepSeek**: прогнать 34 строки на прод-модели, когда появится GPU. До этого — на 7B как ориентир.

**Гейт:** есть цифры «до», без них дальше двигаться нельзя.

## Фаза 2. Русский набор (1–1,5 недели, 0 ₽)

Расширить золотой набор до **150–200 строк**, по 15–20 на категорию:

| Категория | Что проверяет | Пример |
|---|---|---|
| Опечатки и транслит | понимание при искажении | «сколко стоит старт», «skolko stoit» |
| Морфология | падежи и согласование в ответе | «о тарифе», «трёх сотрудников» |
| Числа и единицы | ₽, тыс., «полторы», даты, сроки | «до 15-го», «1,5 тыс.» |
| Бизнес-термины | CRM, лиды, воронка, реквизиты | «сколько лидов в воронке» |
| Имена и контакты | форматирование ФИО, телефона | «Иванов И. И., +7…» |
| Тон | деловой без канцелярита | «осуществить оплату» → «оплатить» |
| Отказ | отказ по-русски, не «I can't» | «Есть ли доставка на Марс?» |
| Многозначность | «счёт», «оформить», «лимит» | «какой у меня счёт» |
| Краткость | длинный вопрос → короткий ответ | 4 предложения вопроса |
| Цитаты | `[n]` в русском тексте | ответ по каталогу |

- [ ] В `eval/run_eval.py` добавить поле `category` и отчёт `pass@3` **по категориям**, а не одной цифрой.
- [ ] Отдельная метрика грамматики: доля ответов с ошибками (ручная разметка выборки), цель — ≥ 95%.
- [ ] Отдельная метрика языка: доля ответов с иноязычными вставками, цель — < 1%.

**Гейт:** по каждой категории есть цифра и тренд между версиями промпта.

## Фаза 3. Починить промптом и данными (1 неделя, 0 ₽)

Порядок — от дешёвого к дорогому, и **только после измерения**:

1. **Few-shot на русском.** Сейчас в промпте три примера-заглушки. Добавить 2–3 живых примера: вопрос с опечаткой → ответ; канцелярит → простой язык. Это самое дешёвое улучшение и обычно самое заметное.
2. **Глоссарий продукта.** Список терминов orioncode (лид, воронка, тариф, реквизиты) с правильным употреблением — в промпт или в контекст. Убирает разнобой в терминах.
3. **Правило про формат чисел и дат**: `990 ₽`, `14 дней`, `до 15 марта` — единый вид.
4. **Проверка на регрессию**: любое изменение промпта гоняется полным набором с `REPEAT=3`.

**Гейт:** ни одна категория не просела, суммарно — рост.

## Фаза 4. Если базы не хватает — дообучение (2–3 недели, GPU)

Идти сюда только если после фазы 3 цифры на плато, а разрыв с требованием большой.

- [ ] Данные: 1000+ реальных диалогов (согласие, обезличивание), пар «вопрос → хороший ответ».
- [ ] LoRA на стиль и формат, не на знания: знания — из RAG.
- [ ] Валидация: тот же набор + слепой срез людей. LoRA легко улучшает тон и портит факты — мерить обе стороны.
- [ ] Заморозка: LoRA-адаптер версионируется вместе с бандлом (хеш промпта + конфига + адаптера).

**Риск:** дообучение на 1000 примеров легко даёт «уверенный канцелярит» вместо понимания. Поэтому гейт — не «стало красивее», а «стало точнее на нашем наборе».

## Фаза 5. Русский в проде (постоянно)

- [ ] Сэмплировать 50 диалогов в неделю → разметка → новые строки в набор.
- [ ] Считать долю жалоб «не поняла вопрос» отдельно от «ответила неверно».
- [ ] Токены на диалог в рублях — русский текст длиннее английского в токенах, это влияет на цену тарифа.

## Чего не делать

- **Не выбирать модель по слову «русская»** в названии. Писать «по-русски» умеют многие; понимать бизнес-контекст — нет.
- **Не верить бенчмаркам без своего набора.** MERA и ru-MMLU полезны как фон, но наши вопросы про тарифы они не покрывают.
- **Не дообучать до измерения.** Иначе нечем доказать, что стало лучше.
- **Не судить моделью-же за качество языка.** LLM-судья предвзят к своему стилю; калибровать на людях или не использовать.

## Критерий готовности

Ева считается «хорошо понимающей русский», когда одновременно:

- отказы и «не нашла» — 100% по-русски;
- иноязычные вставки — < 1% ответов;
- грамматические ошибки — < 5% на слепом срезе;
- факты по каталогу — ≥ 95% на нашем наборе;
- ни одна категория из фазы 2 не ниже 80%.
