# Команды Евы: что умеет, на какие фразы и как отвечает

> Актуально на 2026-11-27.

Одна страница на весь разговорный интерфейс: какие фразы Ева понимает,
что при этом происходит и каким текстом она отвечает. Источник правды —
код, а не замысел: фразы выписаны из регэкспов плагинов, ответы — из строк,
которые эти плагины возвращают. В таблицах — примеры формулировок, а не
исчерпывающий список: варианты задаёт сам регэксп, и любая фраза, которая
ему соответствует, сработает так же.

Как читать таблицы:

| Пометка | Что значит |
|---|---|
| **плагин** | сервер отвечает сам, модель не вызывается; в метриках `finish_reason=plugin` |
| **справка + модель** | плагин добывает цифру, модель формулирует фразу по секции `СПРАВКА` |
| **модель** | ответ генерируется; действий у Евы в этот момент нет |

Порядок важен: плагины со способностью `answer` вызываются по возрастанию
приоритета — `fairy-tales` (20), затем `music` (30). Поэтому «громче»
первым ловит плагин сказок и меняет системный звук Mac; плагин музыки
получает фразу только если сказки её не взяли. Это не опечатка, а
наблюдаемое поведение.

## Быстрый старт

| Как начать | Что происходит |
|---|---|
| **⌥Space** (глобально, из любого приложения) | начать слушать; статус «слушаю…», в окне живой частичный текст; ещё раз — конец записи и вопрос уходит в чат |
| **«Привет, Ева»** | wake-word в `idle`; работает при включённой галочке «Ждать „Привет, Ева“» (по умолчанию выключена: микрофон держится постоянно). Триггер — «привет» + «ева» в любом порядке или «эй ева» рядом |
| **поле ввода + Enter** | вопрос текстом, без микрофона (ответ и озвучка — как обычно) |
| **клик по компактному кругу** | развернуть окно; двойной клик — начать/закончить слушать, как ⌥Space |
| **«Свернуть» / ⌘M** | остаётся круг 140 pt поверх окон; разговор продолжается |

Как прервать:

| Фраза / действие | Что происходит | Ответ |
|---|---|---|
| **«Стоп, Ева»**, «стоп», «хватит», «тише» (галочка «Слушать „Стоп, Ева“», по умолчанию вкл.) | пока Ева думает или говорит: тишина, `POST /api/cancel`, круг в `idle`. Слово-триггер — одно из трёх: `стоп`, `хватит`, `тише` | Ева молчит |
| кнопка **«Стоп»** | то же, что голосом: обрыв генерации и речи | Ева молчит |
| «Стоп, Ева» **во время записи** | слушатель стоп-слова в этот момент выключен (микрофон общий), поэтому «стоп» ловится в распознанном тексте и не уходит в модель | Ева молчит |
| «Стоп, Ева» при играющей записи сказки, музыке или радио | приложение дополнительно зовёт `POST /api/audio/stop`: плагины получают команду «выключи» и глушат `afplay`/Music.app | Ева молчит |

Разговор без кнопок: после ответа (и конца озвучки) микрофон открывается
сам — следующий вопрос можно задать без «Привет, Ева». Работает только
вместе с ожиданием фразы. 12 секунд тишины (варианты 8/12/20) — и Ева
снова ждёт «Привет, Ева». После ошибки ответа follow-up не открывается.

Чтобы всё это работало, нужны две вещи: запущенный сервер
`tools/chat_server.py` (по умолчанию `http://127.0.0.1:8765`) и собранное
приложение EVA.app (`sh tools/build_eva_app.sh`). Без сервера приложение
покажет ошибку вида «сеть: …» / «сервер не ответил», без прав микрофона и
распознавания — не начнёт слушать (причина в журнале приложения).

## Сказки

Корпус офлайн: **29 сказок** в `plugins/fairy-tales/tales/`, **4 готовые
записи** (`.mp3` в `plugins/fairy-tales/audio/`: «Баба-яга», «Кот, петух и
лиса», «Теремок», «Царевна-лягушка») и иллюстрации для 9 сказок в
`plugins/fairy-tales/images/`. Сеть не нужна, разрешений macOS на это не
требуется.

### Просьба и выбор

| Фраза (примеры) | Что произойдёт | Как ответит |
|---|---|---|
| «расскажи сказку», «почитай сказку», «расскажи историю», «прочти сказку», «расскажи что-нибудь интересное ребёнку» | случайная **нестрашная** сказка не длиннее 3500 символов; прошлая не повторяется | «Слушай сказку… „Курочка Ряба“.» + текст + «Сказке конец, а кто слушал — молодец.» |
| «сказку на ночь», «сказку перед сном», «колыбельную сказку», «сказку про ночь» | та же случайная сказка, но с ночной концовкой | «Слушай сказку на ночь… „Колобок“.» + текст + «Вот и сказке конец. Закрывай глазки и засыпай. Сладких снов.» |
| «сказку про лису», «про медведя», «про колобка» | выбор по словам после «про»: совпадение с названием (вес 3) или тегом (вес 2). При равенстве — короче название | «Слушай сказку… „Лиса и рак“.» + текст |
| «волшебную сказку» | только сказки с тегом «волшебная» | «Слушай сказку… „Петушок — золотой гребешок“.» |
| «страшную сказку», «жуткую», «ужасную» | только сказки с тегом «страшная»; случайно страшная не выпадает никогда | «Слушай сказку… „Морозко“.» |
| «короткую сказку» | только сказки до 800 символов (влезают в одну-две фразы озвучки) | «Слушай сказку… „Грибы“.» |
| «сказку для малышей», «маленькую», «ребёнку» | только сказки с возрастом 3+ | «Слушай сказку… „Репка“.» |
| «следующая», «следующую сказку», «ещё сказку», «давай ещё», «другую сказку», «продолжи» | следующая по алфавиту в отфильтрованном наборе; после последней — снова первая | «Слушай сказку… „Пузырь, соломинка и лапоть“.» |
| «какие у тебя есть сказки», «список сказок», «перечисли сказки», «покажи сказки» | первые 10 нестрашных с номерами, чтобы выбрать «номер 3» | «У меня есть сказки: 1. Грибы; 2. Гуси-лебеди; 3. Колобок; … 10. Лиса и журавль. И ещё 16 сказок — скажи „следующая“.» |
| «сколько у тебя сказок», «много ли у тебя сказок» | число словами и три примера названий | «У меня двадцать девять сказок. Например, „Колобок“, „Гуси-лебеди“, „Царевна-лягушка“.» |
| «сказка номер 3», «№ 3», «сказку 3» | сказка по номеру из списка (страшные в нумерации не участвуют) | «Слушай сказку… „Колобок“.» + текст |
| «сказку про слона» (такой нет) | случайной сказкой не подменяется — отвечает модель | «модель»: честно скажет, что такой сказки нет (это не плагин) |

Одна тонкость: просьбу должна выдавать сама фраза — в ней нужно слово
«сказка/сказку/история/почитай/прочти» (или «расскажи» + «ребёнку/что-нибудь
интересное»). Голое «перед сном» или «колыбельную» без этого слова плагин не
берёт: отвечает модель.

Сказки приходят с картинками: до 10 иллюстраций на сказку, позиции — по
границам абзацев. В приложении они показываются, если включена галочка
«Показывать картинки сказок» (по умолчанию включена); на круг и озвучку это
не влияет.

### Готовая запись

Запись включается только для четырёх сказок из списка выше. Если сказка
выбрана, а записи у неё нет, честный отказ — не подмена.

| Фраза (примеры) | Что произойдёт | Как ответит |
|---|---|---|
| «включи запись сказки», «включи аудиосказку», «поставь сказку в исполнении», «давай послушаем сказку» | `afplay` играет `audio/<slug>.mp3`; синтез подтверждения не запускается (`silent`) | «Включаю запись „Царевна-лягушка“.» |
| «включи запись про кота», «аудиосказку про лису» | из подходящих предпочитается та, у которой есть запись | «Включаю запись „Кот, петух и лиса“.» |
| «включи запись сказки», а системный звук ниже 25 % | звук поднимается до 65 %, чтобы не было «включила, но тихо» | «Включаю запись „Теремок“. Сделала громче — было 10 процентов, стало 65.» |
| «включи запись Репки» (записи нет) | `afplay` не запускается | «Записи сказки „Репка“ нет, могу рассказать сама.» |
| «поставь аудиосказку», а записей в каталоге нет вовсе | ничего не играет | «Записей сказок у меня нет, могу рассказать сама.» |
| «выключи запись», «стоп сказку», «прекрати чтение», «останови воспроизведение» | `afplay` получает SIGCONT → terminate → kill по таймауту | «Выключила запись.» |
| «выключи», «стоп», «тишина» (без слова «сказка/запись») | останавливает запись, только если она играет или только что играла; иначе команда уходит музыке или модели | «Выключила запись.» — если было что останавливать |
| «выключи запись», когда ничего не играет | ничего не делает | «Запись сейчас не играет.» |

### Темп чтения записи

Темп относится только к готовой записи (`afplay -r`), не к системной
громкости и не к синтезу. По умолчанию 90 % (детский режим), шаг 5 %,
границы 75…115 %.

| Фраза (примеры) | Что произойдёт | Как ответит |
|---|---|---|
| «медленнее», «помедленнее», «не так быстро» | темп 90 → 85 % (до 75 %) | «Хорошо, буду читать на 85 процентах скорости.» |
| «быстрее», «поскорее», «ускорь» | темп 90 → 95 % (до 115 %) | «Хорошо, буду читать на 95 процентах скорости.» |
| «обычный темп», «нормальная скорость» | темп 100 % | «Хорошо, буду читать на 100 процентах скорости.» |
| те же команды во время игры | запись перезапускается с того же места на новом темпе, ответ silent | «Читаю на 85 процентах скорости.» |
| «медленнее» на нижней границе | темп не меняется | «Медленнее уже нельзя: читаю на 75 процентах скорости.» |
| «быстрее» на верхней границе | темп не меняется | «Быстрее уже нельзя: читаю на 115 процентах скорости.» |
| «медленнее» без контекста чтения, вне игры («расскажи медленно сказку») | это просьба сказки, а не темпа: сказка выбирается и читается как обычно | «Слушай сказку…» |

### Громкость

Это системный звук Mac (`osascript` `set volume output volume`), а не
громкость отдельного плеера: `afplay` своей громкости не имеет и в
интерфейсе её не видно.

| Фраза (примеры) | Что произойдёт | Как ответит |
|---|---|---|
| «громче», «погромче», «прибавь звук», «сделай громче» | системная громкость +15, не выше 100 (например, 75 → 90) | «Громкость — 90 процентов.» |
| «тише», «потише», «убавь звук», «сделай тише» | системная громкость −15, не ниже 0 (например, 90 → 75) | «Громкость — 75 процентов.» |
| «громкость 80», «громкость на 80», «звук на 80» | ровно 80 % | «Громкость — 80 процентов.» |
| «выключи звук», «без звука», «молчком», «mute» | 0 % | «Выключила звук. Скажи „громче“, чтобы вернуть.» |
| «громче» не удалось (osascript не сработал) | плагин молчит, отвечает модель | «модель» |

### Ограничения сказок

- В корпусе 29 сказок, записей — 4, картинок — у 9 сказок. Просьба
  «включи запись» для остальных 25 заканчивается честным «могу рассказать
  сама», а не выдуманным воспроизведением.
- Файл записи больше 3 МБ не играется — считается, что это уже не короткая
  запись.
- Страшные сказки не выбираются случайно и не попадают в список: только по
  явной просьбе «страшную».
- «Сказку про слона» Ева не подменяет случайной: если совпадений нет,
  отвечает модель.
- Готовая запись не пересказывается моделью: синтез поверх записи не
  запускается (`silent: true` в событии `delta`).

## Музыка и радио

Музыкой управляет **Music.app** через `osascript` (одна AppleScript-команда
на фразу, таймаут 5 с). Радио играет через `afplay` по публичным потокам и
Music.app не требует. Первый запрос к Music.app может ждать **TCC-диалога**
«разрешить управлять Music»: пока диалог не подтверждён, команда честно
отвечает «macOS не разрешила…» (см. ниже).

Что важно знать заранее: **«громче» и «тише» достаются плагину сказок** —
он первый по приоритету и меняет системный звук Mac. Ответ поэтому
«Громкость — 90 процентов.», а не «Сделала громче.» из плагина музыки; для
радио и Music.app это работает так же, потому что звук системный.

### Music.app

| Фраза (примеры) | Что произойдёт | Как ответит |
|---|---|---|
| «включи музыку», «поставь музыку», «вруби музон», «включи плеер», «включи трек», «включи что-нибудь» | `tell application "Music" to play`; радио перед этим гасится, чтобы не играли два потока | «Включаю музыку.» |
| «включи Кино», «поставь песню Кино», «включи группу Кино», «хочу послушать Кино» | поиск по библиотеке: плейлист → трек по названию → трек по исполнителю | «Включаю „Кино“.» |
| «включи плейлист дорога» | первым ищется плейлист по имени | «Включаю плейлист „Дорога“.» |
| «включи Кино», а в библиотеке нет | ничего не включается | «Не нашла в библиотеке „Кино“.» |
| «пауза», «паузу», «на паузу», «поставь музыку на паузу», «приостанови», «pause» | `pause` | «Пауза.» |
| «продолжи», «продолжай», «играй дальше», «сними с паузы», «возобнови», «resume» | `play` | «Продолжаю.» |
| «следующая», «следующий трек», «дальше», «переключи на следующий», «next» | `next track` | «Следующая.» |
| «предыдущая», «назад», «верни трек», «previous» | `previous track` | «Предыдущая.» |
| «что играет», «что сейчас играет», «что за песня», «какая музыка играет», «какой трек», «now playing» | читает состояние и текущий трек | «Играет: Кино — Группа крови.» / «На паузе: Кино — Группа крови.» / «Сейчас ничего не играет.» |
| «громче», «прибавь», «увеличь громкость» | громкость Music.app +10 (0…100); на практике раньше срабатывает плагин сказок и меняет системный звук | «Сделала громче.» (Music.app) или «Громкость — N процентов.» (плагин сказок) |
| «тише», «убавь», «уменьши громкость» | громкость Music.app −10 | «Сделала тише.» / «Громкость — N процентов.» |
| «заглуши», «выключи звук», «без звука», «mute» | громкость Music.app = 0 | «Звук выключен.» |
| «включи звук», «верни звук», «сними mute», «unmute» | громкость Music.app = 50 | «Звук включён.» |
| «выключи музыку», «останови музыку», «стоп», «хватит музыки», «stop» | `stop` | «Выключила музыку.» |
| «включи свет», «включи чайник», «включи телевизор», «включи будильник», «включи wi-fi» | это не музыка: плагин намеренно молчит (список `_NON_MUSIC`) | «модель»: свет не включится, Ева ответит текстом |

Про «следующая»: если до этого рассказывалась сказка, слово «следующая»
перехватит плагин сказок и продолжит сказки, а не трек. Пока сказок в
сессии не было — команда уходит музыке.

### Радио

| Фраза (примеры) | Что произойдёт | Как ответит |
|---|---|---|
| «включи радио», «поставь радио», «вруби радио» | Европа Плюс по умолчанию (`settings.default_radio: europa`) | «Включаю радио Европа Плюс.» |
| «включи радио DFM», «включи дфм», «включи наше радио» | станция из зашитого списка | «Включаю радио DFM.» / «Включаю радио Наше Радио.» |
| «включи европу плюс», «включи дфм» (без слова «радио») | эти названия распознаются как станции | «Включаю радио Европа Плюс.» |
| «включи радио маяк» (станции нет) | ничего не играет | «Такой радиостанции у меня нет — есть Европа Плюс, DFM, Наше Радио.» |
| «пауза» во время радио | `SIGSTOP` процессу `afplay` | «Пауза.» |
| «продолжи» во время радио | `SIGCONT` | «Продолжаю.» |
| «следующая» / «предыдущая» во время радио | переключать нечего | «В радио нет следующего трека.» / «В радио нет предыдущего трека.» |
| «что играет» во время радио | состояние радио важнее Music.app | «Играет радио Европа Плюс.» |
| «выключи», «выключи радио», «стоп» | процесс `afplay` завершается | «Выключила радио.» |
| нет сети или поток не открылся | `afplay` падает за 0,3 с, плагин это замечает | «Не получилось включить радио: поток не открылся.» |
| нет `afplay` (не macOS) | процесс не стартовал | «Не получилось включить радио: на этом Mac нет afplay.» |

Станции зашиты в код: Европа Плюс (`ep128.hostingradio.ru`), DFM
(`dfm.hostingradio.ru`), Наше Радио (`nashe1.hostingradio.ru`). Добавить
свою станцию из чата нельзя.

### Если macOS не разрешила (TCC)

| Что видно | Причина | Что делать |
|---|---|---|
| «macOS не разрешила управлять Music.app — включите автоматизацию в настройках.» | TCC отказал в автоматизации (`-1743`, `-10004`, «not authorized») | Системные настройки → «Конфиденциальность и безопасность» → «Автоматизация» → разрешить терминалу (или EVA.app) управлять Music |
| «Music.app не отвечает: macOS, похоже, ждёт разрешения на автоматизацию.» | диалог TCC никто не подтвердил за 5 с (headless-сессия) | подтвердить диалог один раз вручную или выдать разрешение в «Автоматизации» |
| «Не удалось управлять Music.app: приложение закрыто или вернуло ошибку.» | Music.app закрыт или вернул неизвестную ошибку | открыть Music.app и повторить |
| «Music.app не нашла нужный объект — возможно, он удалён из библиотеки.» | объект исчез из библиотеки | проверить библиотеку Music |
| «Не могу управлять музыкой: на этом Mac нет osascript.» | среда без macOS-утилит | музыка недоступна, чат работает |

Радио и запись сказок идут через `afplay` и разрешения на автоматизацию
**не требуют** — только звук. А вот чтобы попросить их голосом, приложению
нужны разрешения «Микрофон» и «Распознавание речи» (см. раздел
«Деградация»).

## Данные: время, курсы, котировки

Ответ на такие вопросы собирается в два шага: плагин достаёт **факт** и
кладёт его в конец запроса секцией `СПРАВКА` с командой «используй эти
данные дословно; не говори, что данных нет», а модель формулирует фразу.
Если модель всё-таки отказывается («не могу предоставить»), страж
подменяет ответ самой справкой — цифра доходит до пользователя. Поэтому в
колонке «как ответит» ниже — строка факта, а не дословный ответ модели:
формулировка свободная, цифры и источник — из факта.

| Фраза (примеры) | Что достаёт | Как ответит |
|---|---|---|
| «который час», «сколько времени», «точное время», «сколько сейчас на часах» | системные часы, часовой пояс MSK | «26 ноября 2026, 15:30 MSK (часы сервера)» |
| «какое сегодня число», «какая дата» | те же часы, без дня недели | «26 ноября 2026, 15:30 MSK (часы сервера)» |
| «какой сегодня день», «какой день недели» | те же часы + день недели | «четверг, 26 ноября 2026, 15:30 MSK (часы сервера)» |
| «курс доллара», «сколько стоит доллар», «по чём доллар» | XML ЦБ РФ (`cbr.ru/scripts/XML_daily.asp`), кэш 1 час | «1 USD = 78,1234 ₽ (ЦБ РФ на 26.11.2026)» |
| «курс евро», «курс юаня» | тот же срез ЦБ | «1 EUR = 90,5678 ₽ (ЦБ РФ на 26.11.2026)» |
| «курс валют», «курс ЦБ», «курс центробанка» | USD, EUR, CNY одним ответом | три строки: «1 USD = …; 1 EUR = …; 1 CNY = …» с источником «ЦБ РФ на …» |
| «цена акции Сбер», «сколько стоит акция Газпром», «котировки Яндекса», «акции Лукойла» | MOEX ISS, доска `TQBR`, цена последней сделки | «SBER (Сбербанк) = 285,10 ₽, за день -2,32 ₽ (-0,81 %)» + источник «MOEX ISS, 26.11.2026 14:59 MSK» |
| «индекс мосбиржи», «индекс МосБиржи», «IMOEX» | MOEX ISS, доска `SNDX`, поле `CURRENTVALUE` | «Индекс Мосбиржи (IMOEX) = 2 333,84 п., за день -0,52 %, обновлено …» + «MOEX ISS» |
| «индекс РТС», «RTSI» | тот же запрос по RTSI | «Индекс РТС (RTSI) = … п., за день …» |
| «что входит в индекс мосбиржи», «какие акции в топе индекса Мосбиржи», «состав индекса», «топ по индексу» | два запроса: состав с весами (ISS analytics) и цена каждой из пяти бумаг | «Индекс Мосбиржи (IMOEX), топ по весу (цена, вес): SBER (Сбербанк) — 285,17 ₽, вес 12,34 %; … Назови каждую бумагу с её ценой.» (дальше — модель) |
| «сколько времени ехать до офиса», «сколько ждать доставку» | это длительность, а не часы: факт времени не подставляется | «модель» (в гибридном сервере — скилл каталога) |
| «тариф», «подписка», «доставка», «возврат», «офис», «поддержка» + слово «цена/курс» | служебный вопрос каталога: роутер намеренно молчит | «модель» / каталог гибридного сервера |
| «какие акции в топе индекса» (индекс не назван) | не распознаётся: нужен «индекс» + «мосбиржи/РТС/IMOEX» | «модель» |

Источники и ограничения:

| Что | Значение |
|---|---|
| Курс валют | XML ЦБ РФ, `https://www.cbr.ru/scripts/XML_daily.asp`; кэш 3600 с; курс официальный, обновляется раз в день |
| Котировки | MOEX ISS, `https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities/<тикер>.json`; кэш 60 с |
| Индексы | MOEX ISS, доска `SNDX`; состав — `…/index/analytics/<тикер>.json` |
| Таймаут запроса | 4 с — чат не ждёт сеть дольше, чем думает |
| Валюты | ISO-коды и русские названия: доллар, евро, юань, фунт и т. д. (кроме рубля: рубль — не курс) |
| Бумаги | тикеры MOEX и русские названия: Сбер, Газпром, Яндекс, Лукойл … |
| Других источников нет | нет ЦБ других стран, нет крипты, нет зарубежных бирж, нет истории цен |

Если источник не ответил, в справку попадает честная строка, а не
выдуманная цифра:

| Что сломалось | Строка факта |
|---|---|
| нет сети / ЦБ не ответил | «не удалось получить курс USD — нет ответа от ЦБ РФ» |
| нет сети / MOEX не ответил | «не удалось получить котировку SBER — нет ответа от MOEX» |
| индекс не получен | «не удалось получить индекс IMOEX — нет ответа от MOEX» |
| топ индекса не получен (состав или цены) | факта нет вовсе → отвечает модель («не нашла данных») |
| модель ответила отказом при наличии факта | страж подменяет отказ самой строкой факта |

## Обычный разговор

Всё, что не взяли плагины, отвечает модель. Это не «умный дом» и не агент:
у модели нет инструментов, она только пишет текст.

| Фраза (примеры) | Что произойдёт | Как ответит |
|---|---|---|
| «привет», «как дела», «расскажи анекдот», «объясни, что такое инфляция» | обычная генерация с системным промптом | свободный текст; о себе — в женском роде: «я поняла», «я готова» |
| «напиши пост для клиентов», «улучши текст», «сделай заголовки» | маркетинговая зона промпта | текст; на неполную задачу — 2–4 уточняющих вопроса |
| «сколько стоит ваш тариф» без каталога | в этом чате каталога нет | «Не нашла в данных» + один уточняющий вопрос (правило промпта), а не выдуманная цена |
| «я понял» в ответе модели | `plugins/ru-gender` и страховка ядра меняют род в потоке | «я поняла» |
| длинный ответ | лимит `max_tokens` (по умолчанию 1024) | ответ обрывается на середине; в веб-панели `finish_reason=length` → «лимит токенов» |
| «Стоп» во время ответа | отмена генерации | `finish_reason=cancelled`, недописанный ответ в историю не попадает |

Что стоит знать:

- **Женский род** — не пожелание, а фильтр: `plugins/ru-gender`
  (`filter.run`, `scope=all`) правит поток, историю и озвучку; ядро
  дублирует это на случай выключенного плагина.
- **«Не знаю» вместо выдумки** — правило промпта: «Конкретные цифры — цены,
  сроки, лимиты — не выдумывай… если данных нет — „Не нашла в данных“ и
  один уточняющий вопрос». Для фактов это подкреплено стражем: отказ
  модели при наличии справки заменяется самой справкой.
- **Служебные пометки не видны**: `plugins/ru-facts` вырезает `[Факт: …]`,
  `СПРАВКА:` и `(источник: …)` из ответа.
- **Числа перед озвучкой** становятся словами: `plugins/ru-numbers`
  (`scope=tts`) — «1500» → «тысяча пятьсот».
- **История диалога** хранится на колонку сервера: Ева помнит предыдущие
  реплики, `POST /api/reset` начинает новый диалог.
- **Длина фразы для озвучки — 600 символов.** Более длинный текст
  `/api/tts` отвергает: «Фраза длиннее 600 символов — разбейте её на
  части.» Приложение режет ответ на фразы само, поэтому в обычном
  разговоре это не видно.
- **Голос** синтезируется цепочкой ElevenLabs → Silero → `say`/`espeak`.
  Если не осталось ни одного движка — 503 «голос недоступен», а текст
  ответа всё равно печатается.

## Чего Ева не умеет

Это важнее списка умений: ниже — то, чего в коде **нет**. Никакого плагина,
инструмента или API за этими фразами не стоит, поэтому действие не
произойдёт. Ответ в таких случаях пишет модель, и он зависит от неё;
гарантировано только одно — Ева не станет делать вид, что выполнила
команду, потому что выполнять нечем.

| Просьба (примеры) | Что произойдёт на самом деле | Чего ждать в ответ |
|---|---|---|
| «какая погода», «будет ли дождь», «погода на завтра» | нет источника погоды: роутер намеренно молчит | текст модели без цифр; прогноза не будет |
| «найди в интернете», «погугли», «что пишут в новостях» | веб-поиска нет; сеть разрешена пяти хостам: ЦБ, MOEX и трём радиостанциям | «не могу искать в интернете» / общие знания модели |
| «включи свет», «выключи лампу», «включи чайник», «кондиционер», «розетку» | умного дома нет; плагин музыки такие слова намеренно пропускает (`_NON_MUSIC`) | текст; ничего не включится |
| «вызови такси», «закажи доставку», «забронируй столик» | заказа и внешних сервисов нет | текст; заказ не создастся |
| «поставь будильник», «таймер на 10 минут», «напомни завтра» | будильников и напоминаний нет; это не зона плагинов | текст; напоминание не сработает |
| «включи камеру», «запиши звук», «сделай скриншот» | захвата экрана/камеры/записи звука в коде нет | текст; записи не будет |
| «поиграем в игру», «викторина» | игр нет | текст (в лучшем случае — текстовая игра словами) |
| «проверь почту», «что в календаре», «отправь письмо» | доступа к почте и календарю нет | текст |
| «позвони», «отправь сообщение» | телефонии и мессенджеров нет | текст |
| «купи», «оплати», «переведи деньги» | платежей нет | текст |
| «сохрани файл», «открой документ» | файловых операций из чата нет: плагины читают только свои каталоги | текст |
| «курс биткоина», «цена на нефть», «акции Apple», «история цен Сбера» | поддерживаются только ЦБ РФ (валюты) и MOEX ISS (акции TQBR и индексы IMOEX/RTSI) | «не нашла данных» / текст модели |
| «включи радио Record», «добавь станцию» | станции зашиты в код: Европа Плюс, DFM, Наше Радио | «Такой радиостанции у меня нет — есть Европа Плюс, DFM, Наше Радио.» |
| «сказку про слона» (нет в корпусе) | подмены случайной сказкой нет | «модель»: честно скажет, что такой сказки нет |

## Деградация: нет сети, нет разрешений, нет записи

| Ситуация | Что увидит пользователь | Что делать |
|---|---|---|
| **Нет сети, вопрос про курс** | «не удалось получить курс USD — нет ответа от ЦБ РФ» (в ответе — эта же мысль) | проверить сеть; курс ЦБ кэшируется на час, поэтому срез часовой давности ещё может ответить |
| **Нет сети, вопрос про акцию/индекс** | «не удалось получить котировку SBER — нет ответа от MOEX» / «не удалось получить индекс IMOEX — нет ответа от MOEX» | проверить сеть; котировки кэшируются на 60 с |
| **Нет сети, «включи радио»** | «Не получилось включить радио: поток не открылся.» | включить музыку из библиотеки Music.app (сеть не нужна) |
| **Нет Music.app / TCC не выдан** | «macOS не разрешила управлять Music.app — включите автоматизацию в настройках.» или «Music.app не отвечает: macOS, похоже, ждёт разрешения на автоматизацию.» | «Конфиденциальность и безопасность» → «Автоматизация» → разрешить управление Music; подтвердить диалог один раз вручную |
| **Нет `osascript`** (не macOS) | «Не могу управлять музыкой: на этом Mac нет osascript.» | музыка недоступна; сказки и чат работают |
| **Нет записи сказки** | «Записи сказки „Репка“ нет, могу рассказать сама.» / «Записей сказок у меня нет, могу рассказать сама.» | сказать «расскажи сказку» — Ева прочитает текстом |
| **Запись не открылась** (битый файл, нет прав) | «Не получилось включить запись: файл не открылся.» | пересобрать/проверить файл в `plugins/fairy-tales/audio/` |
| **Нет `afplay`** | «Не получилось включить запись: на этом Mac нет afplay.» | macOS-утилиты нужны; на Linux остаётся текст |
| **Системный звук почти выключен** | запись всё равно заиграет, а Ева предупредит: «Сделала громче — было N процентов, стало 65.» | ничего: громкость уже поднята |
| **Нет прав на микрофон/распознавание** | ⌥Space и «Привет, Ева» не начинают запись, в журнале — причина | «Конфиденциальность и безопасность» → «Микрофон» и «Распознавание речи» → разрешить EVA.app; после пересборки ad-hoc подписи разрешение может спроситься снова |
| **Сервер не запущен** | приложение: «сеть: …» / «сервер не ответил (…)» | `python3 tools/chat_server.py --port 8765`; адрес сервера — в настройках |
| **Голосовой движок недоступен** | 503 «голос недоступен» в статусе; текст ответа печатается | `sh tools/install_silero.sh` или системный `say` |
| **Корпус сказок пуст** (нет `tales/*.md`) | плагин сказок молчит | восстановить корпус; это не «нет сказок», а «нет файлов» |
| **Модель ответила отказом, а факт был** | ответ заменяется строкой факта | ничего: это защита от «не могу предоставить» |

## Настройки

Приложение хранит настройки в `UserDefaults` домена `com.eva32.eva`
(`defaults write com.eva32.eva …`), сервер — в флагах `tools/chat_server.py`
и `config/plugins.json`.

| Ключ / флаг | По умолчанию | Смысл |
|---|---|---|
| `eva.serverURL` | `http://127.0.0.1:8765` | адрес чат-сервера |
| `eva.modelSpec` | `vtm` · `runs/q4/3b-q4k.vtm` | пара «бэкенд · модель» из `GET /api/backends` |
| `eva.voice` | `baya` | голос Silero: `baya` (живой), `kseniya` (выше), `xenia` (ниже); `aidar` валиден в API, но в UI не показывается. Старые пресеты (`young`/`soft`/`irina`) читаются как `baya` |
| `eva.speakReplies` | `true` | озвучивать ответы; выключено — только текст |
| `eva.showTaleImages` | `true` | «Показывать картинки сказок»; `false` — только текст |
| `eva.talePace` | `slow` | «Скорость чтения сказок»: `slow` — паузы между фразами и абзацами ×1,8, `normal` — как в чате; смена действует без перезапуска |
| `eva.maxTokens` | `1024` | `max_tokens` запроса; `1024` — потолок, который модель ещё отдаёт целиком |
| `eva.animateCircle` | `true` | анимация большого круга; `false` — статичный круг и ноль кадров |
| `eva.wakeWord` | `false` | ждать «Привет, Ева» в `idle` (постоянный микрофон) |
| `eva.followUpListen` | `true` | «Слушать после ответа»; работает только вместе с ожиданием фразы |
| `eva.followUpSilence` | `12` | секунд тишины в follow-up; варианты в UI — 8/12/20 |
| `eva.stopCommand` | `true` | «Слушать „Стоп, Ева“»: микрофон только на время «думаю»/озвучки |
| `eva.startCompact` | `false` | «Запускаться свёрнутым»: на экране только круг |
| `eva.compactX`, `eva.compactY` | — | позиция компактного круга; зажимается в видимой области экрана |
| `--max-tokens` (сервер) | `1024` | лимит ответа по умолчанию для всех клиентов |
| `--no-system-prompt` | выкл. | не подмешивать `prompts/system.assistant.md` |
| `settings.timeout` (`music`) | `5.0` | сколько ждать AppleScript, прежде чем ответить честным «не удалось» |
| `settings.default_radio` (`music`) | `europa` | станция для «включи радио» без названия |
| `config/plugins.json` → `enabled` | все 8 | включённые плагины: `time`, `currency`, `stocks`, `fairy-tales`, `music`, `ru-numbers`, `ru-gender`, `ru-facts` |

Плагины можно включать и выключать без перезапуска: `GET /api/plugins` —
список, `POST /api/plugins {"id": "music", "enabled": false}` — переключить
(409, если плагин держит состояние). Выключенный плагин просто молчит: его
фразы уходят модели, а не отвечают ошибкой.

Голоса — только три в интерфейсе и четыре в API:

| Голос | Как звучит | Где доступен |
|---|---|---|
| `baya` | живой, по умолчанию | UI и API |
| `kseniya` | выше | UI и API |
| `xenia` | ниже | UI и API |
| `aidar` | — | только API (`/api/tts`) |

## Как эта страница проверяется

`python3 tools/check_commands_doc.py` — механическая проверка этой страницы:

- файл `docs/commands.md` существует и содержит строку «Актуально на
  ГГГГ-ММ-ДД»;
- упомянуты все id плагинов, которые включает `config/plugins.json`
  (`time`, `currency`, `stocks`, `fairy-tales`, `music`, `ru-numbers`,
  `ru-gender`, `ru-facts`), плюс обязательный список из задачи;
- есть ключевые слова-фразы: «стоп», «сказк», «курс», «акци», «музык»,
  «радио», «громче», «номер», «индекс»;

`python3 tools/ci.py`. Правило даты общее для всех документов: меняешь
страницу — ставь сегодняшнюю дату, иначе `tools/check_docs_dates.py`
покраснеет через 30 дней.
