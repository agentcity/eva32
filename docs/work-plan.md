## Где мы

- Бандл собран: карточка, промпт v2, конфиг, сервинг, контракт, eval из 34 строк, чек-лист GPU.
- Закреплена ревизия весов `60d8d70…`, есть `NOTICE`, версия `1.0.1`.
- Замеры только на стенде (qwen 3B/7B), **DeepSeek не запускался ни разу**.

## Ограничения, которые формируют план

1. **Без GPU нет измерений** — а без измерений любая правка промпта или квантования слепая.
2. **Ноутбук занят чужими процессами** — модель на нём поднимаю только по прямой просьбе.
3. **Продукт не может ждать железа** — то, что не требует GPU, двигается параллельно.

## Что не делаем сейчас (и почему)

- **Своя vLLM / свои ядра** — годы работы, результат хуже готового Apache-2.0.
- **QAT 284B в триты** — без гейта на 2–3B это ставка вслепую.
- **distributed-db под RAG** — в нём нет векторов, а pgvector есть сегодня.
- **Дообучение (LoRA)** — только после плато на промпте и набора в 150+ строк.

## Критический путь

```
аренда GPU ──> эталон ──> русский набор ──> промпт v3 ──> Q4/триты ──> решение по железу
                                   └──> RAG (orioncode) ──> прод
```

Всё упирается в первую стрелку. Остальное можно вести параллельно, но без эталона сравнивать
не с чем.
