# ADR 0022. Плагины: Ева растёт расширениями, а не пересборкой

Дата: 2026-11-26
Статус: принято (архитектура), реализация — задачами 0209+
Связано: [0020](0020-clients-and-cloud.md)

## Контекст

Возможности Евы сейчас размазаны по коду: скиллы в `eva/skills`, речевые
нормализаторы в `eva/ru_*.py`, TTS-движки в `eva/tts.py`, данные в
`tools/chat_server.py`. Чтобы добавить «курс акций» или «погоду», нужно править
ядро. Это не масштабируется: продукт должен расти **подключением плагинов**, как
у DeepSeek Harness — поставить/включить/выключить, не трогая ядро.

## Решение

1. **Плагин — каталог** `plugins/<id>/` с манифестом `plugin.json`:
   `id`, `name`, `version`, `api` (версия контракта, сейчас 1), `entry`
   (python-модуль), `capabilities`, `permissions` (`network: [hosts]`,
   `filesystem: [paths]`), `settings` (схема), `description`.
2. **Точки расширения (capabilities)**:
   - `skill.fetch(ctx)` — достать факт по вопросу (время, курсы, котировки,
     погода, каталог). Ядро подкладывает факт в промпт до генерации.
   - `filter.run(text)` — постобработка ответа (числа в слова, женский род,
     чистка разметки). Порядок задаётся приоритетом.
   - `tts.engine` — альтернативный синтез речи.
   - `command` — слэш-команды чата (`/погода Москва`).
   - (позже) `ui.panel` — панель в EVA.app.
3. **Жизненный цикл**: discovery при старте → проверка манифеста → загрузка
   включённых (`config/plugins.json`) → регистрация способностей → вызовы.
   Выключение — без перезапуска, если плагин это поддерживает; иначе требует
   рестарт и говорит об этом.
4. **Изоляция и права**: плагин объявляет `permissions`; рантайм **не даёт**
   сеть/файлы вне разрешённого (best-effort: запрет сокетов к чужим хостам,
   проверка путей). Отказ — явная ошибка плагина, а не тихое игнорирование.
5. **Версионирование**: `api: 1` в манифесте; ядро отклоняет плагины с чужой
   версией API и говорит, какая поддерживается.
6. **Первые плагины (dogfooding)**: `time`, `currency`, `stocks` (из 0208),
   `numbers-ru` и `gender-ru` (фильтры) — переезжают в плагины, ядро остаётся
   без них работоспособным.

## Последствия

- Ядро перестаёт знать про конкретные данные: только «вызови skills, собери
  факты, подложи в промпт».
- У пользователя появляется способ расширять продукт: положить каталог в
  `plugins/`, включить — и в чате появляется новая возможность.
- Появляется ответственность за контракт: `plugin.json` и API стабильны,
  изменения — через `api: 2`, а не «на лету».
- Безопасность: плагин — это код, который мы запускаем. Permissions и явный
  список источников — минимум; полноценная песочница — отдельный шаг.
- Для облака (ADR 0020) плагины становятся головной болью мультиарендности:
  чьи плагины, чьи права. Закладываем `owner` в манифест уже сейчас.
