# ADR 0014: данные пилота — программирование на русском

- Статус: accepted
- Дата: 2026-11-18
- Контекст: подготовка QAT-прогона

## Контекст

Для QAT было **206 пар** из 13 демонстрационных позиций каталога. На таком объёме
модель 1.5B за 3 эпохи переобучается и разучивается отвечать на всё остальное: любой
прогон показал бы «плохо» независимо от режима квантования.

Правильный набор — каталог orioncode, но его выгрузка (задача 0007) заблокирована
на стороне данных. Ждать означало остановить весь эксперимент.

## Решение

Данные пилота — **вопросы по программированию на русском** (Python, JavaScript, SQL,
алгоритмы, Git, Linux, ООП, async, тестирование, безопасность), ответы учителя
DeepSeek V4.1 Flash. Цель — ~4 000 пар.

Причины выбора именно этой области:

1. **Учитель не галлюцинирует.** Программирование проверяемо: код либо работает, либо
   нет. В отличие от «сколько стоит тариф», где учитель может выдумать число.
2. **Данные однородны.** Для эксперимента «none/int8/trit» предметная область
   не важна — важно, чтобы все три прогона учились на одном и том же.
3. **Учитель силён.** DeepSeek хорошо пишет код, значит дистилляция даёт чистый сигнал.

## Последствия, которые надо помнить

- **Модель станет помощником по коду, а не по бизнесу orioncode.** Факты о тарифах,
   сроках и возвратах остаются в скиллах и RAG (ADR 0009) — они не требуют обучения.
- **Каталог остаётся демонстрационным.** Когда появится выгрузка (0007), данные
  пилота перегенерируются под продукт, а не «дополнятся» чужим доменом.
- **Выводы эксперимента 0027 переносятся не автоматически.** Мы измерим влияние
  квантования эмбеддингов на кодовых данных; перенос на бизнес-домен — предположение,
  которое надо будет перепроверить.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Ждать выгрузку каталога | останавливает весь эксперимент на неопределённый срок |
| Взять открытый русский датасет | нет контроля качества, лицензии и формата «вопрос→ответ» под наш контракт |
| 206 пар каталога | переобучение, любой результат неинформативен |
| Общие знания «обо всём» | учитель ошибается, ошибки попадут в веса без возможности проверить |
