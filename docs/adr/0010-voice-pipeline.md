# ADR 0010: Голос как транспорт — ASR → текст → LLM → текст → TTS

- Статус: accepted
- Дата: 2026-11-18
- Контекст: голосовой режим ассистента

## Контекст

Пользователь хочет голосового ассистента уровня «Алиса». Соблазн — «сделать
голосовую модель», но это другой класс задач (аудио-LLM) и не наш масштаб.

Проверено на машине: `ffmpeg`, `whisper`, `sox`, `piper` не установлены; из
готового есть `say` с русским голосом Milena (ru_RU).

## Решение

Голос — **отдельный транспортный слой**, модель остаётся текстовой:

```
микрофон → VAD → ASR (речь в текст) → гибрид eva (текст) → TTS (текст в речь) → динамик
```

1. **VAD** определяет конец фразы (иначе ассистент ждёт вечно или обрывает).
2. **ASR** — локальный `whisper.cpp` (C++, работает на Apple Silicon через Metal,
   не требует Python и сети). Модель — small/medium, для русского.
3. **LLM** — уже существующий гибрид: скиллы → малая модель → большая.
4. **TTS** — на старте `say -v Milena` (ноль стоимости, мгновенно, годится для
   отладки конвейера), затем Silero TTS или Piper (лучше качество, CPU, без сети).

## Почему так, а не иначе

| Вариант | Почему нет |
|---|---|
| Аудио-LLM (речь на входе модели) | другой класс моделей и бюджет; у нас нет ни данных, ни GPU |
| Облачный ASR/TTS с первого дня | зависимость, цена за минуту, данные уходят наружу |
| Только облако, как у Алисы | мы строим своё и дешёвое — иначе нет смысла |
| Локально и только локально | качество русского ASR на слабом железе может не устроить — оставляем дверь к облаку |

## Бюджет задержки

| Этап | Ожидание |
|---|---|
| VAD (конец фразы) | 200–300 мс |
| ASR, фраза 5 с | 300–500 мс (small), ~1 с (medium) |
| Маршрут + скилл | <10 мс |
| Малая модель, первый токен | 50–200 мс |
| Большая модель, первый токен | 400–800 мс |
| TTS, первый фрагмент | 50 мс (`say`), 150–300 мс (Silero) |
| **Итого до первого звука** | **1,0–1,8 с** |

Это сопоставимо с Алисой. Ускорение — за счёт потокового TTS по предложениям:
начинаем говорить, не дожидаясь конца ответа.

## Последствия

- **Появляется задержка**, которой нет в текстовом чате; её надо измерять, а не
  обсуждать.
- **Перебивание (barge-in)** — самая сложная часть: нужно глушить TTS, когда
  пользователь начал говорить. В v1 не делаем, отмечаем как ограничение.
- Формат транспорта: WAV/PCM 16 кГц моно на входе, поток чанков на выходе.
- Текстовый API (`/v1/chat/completions`) не меняется — голос лишь обёртка.
- Пересматриваем, если: качество локального ASR на русском окажется ниже
  приемлемого — тогда облачный ASR как опция, с явным переключателем.
