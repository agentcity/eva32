# ADR 0004: Путь к троичной модели — дистилляция + QAT, не PTQ

- Статус: accepted
- Дата: 2026-11-18
- Контекст: как получить троичную Еву

## Контекст

Базовая модель — DeepSeek V4-Flash, 284B параметров, 159,6 ГБ в FP8. В тритах
это 56 ГБ, но **пережать нельзя**: тернарные веса получаются обучением, а не
округлением — при простом округлении модель рассыпается.

Меньшая модель (1.5–3B) в тритах — 0,9–1,4 ГБ, влезает в обычный сервер. Но она
не знает того, что знает учитель: знания должны прийти из данных и RAG.

## Решение

**Дистилляция поведения учителя в ученика 1.5–3B с одновременным QAT.**
Учитель — V4.1-Flash по API (polza.ai), ученик — Qwen2.5-1.5B-Instruct,
тернарными становятся только Linear-слои.

Порядок: пилот на 1.5B (10 тыс. пар, ~113 ₽ данных, 8 GPU-часов) → проверка
качества против Qwen 1.5B Q4 → решение о 3B.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| PTQ (округлить 284B в триты) | качество рушится: нужен QAT, иначе шум квантования накапливается по слоям |
| QAT с нуля на триллионах токенов (как BitNet) | месяцы и кластер; у нас нет ни того, ни другого |
| Дообучение V4.1 (LoRA) | FP8-веса 510 ГБ → 8–32 H100; не наш масштаб |
| Оставить FP8 и купить 8×H100 | 15 млн ₽ за стойку против 150–250 тыс за сервер |
| Ждать троичного железа | модель всё равно надо обучать заранее, иначе нечего исполнять |

## Последствия

- Качество ограничено 1.5–3B: реалистичная цель — 80% типовых вопросов продукта,
  остальное через API.
- 6–8 недель и ~2 тыс ₽ на версию 1; дорого — не GPU, а итерации.
- Зависимость от данных: без каталога продукта (задача 0007) дальше золотого
  набора не уехать.
- Пересматриваем, если: пилот не пройдёт планку качества (тогда — 3B или
  гибрид «малая модель + API»).
