# ADR 0001: Стек по слоям — C99, C++17, Python, Go

- Статус: accepted
- Дата: 2026-11-18
- Контекст: рантайм ВТМ, обучение, данные

## Контекст

Проект живёт в четырёх разных задачах одновременно: обучение троичной модели,
сбор данных, исполнение модели и (в будущем) сервис. Один язык на всё означает
компромисс в трёх из четырёх.

Ограничения: без GPU на машине разработки; горячий цикл — умножение матрицы на
вектор, где каждый элемент — трит; в перспективе — другое железо (фотоника), то
есть ядра должны быть заменяемы; над репозиторием работают до восьми агентов, и
сборка должна оставаться простой.

## Решение

| Слой | Язык |
|---|---|
| Ядра (TMV, распаковка тритов) | C99, экспорт по C-ABI |
| Ядро ВТМ (загрузчик, интерпретатор, KV, токенизатор) | C++17 |
| Обучение QAT, данные, компилятор графа | Python 3.10+ |
| Сервис (API, стриминг, метрики) | Go — когда дойдём |

C остаётся там, где он лучший: цикл по тритам. C++17 — там, где нужны RAII,
контейнеры и разбор недоверенного файла без segfault. Python — там, где
autograd и быстрое прототипирование. Go — только сервисный слой.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Go на всё | нет интринсиков (NEON/AVX только через asm/cgo, то есть ядро всё равно в C); GC в горячем цикле; нет ML-экосистемы |
| Rust на ядро | безопасность памяти и та же скорость, но SIMD неудобнее, экосистема тонкая, borrow checker в горячем коде = недели |
| Чистый C на всё | разбор JSON/файлов вручную, segfault вместо ошибки, ручная память в токенизаторе |
| C++ на всё | ядра на C проще стыкуются с ассемблером и SIMD; C-ABI — стабильная граница между «горячим» и «умным» кодом |

## Последствия

- В рантайме два языка и FFI-граница: интерфейс ядер замораживается раньше,
  чем всё остальное.
- Python обязателен для обучения — альтернатив нет, autograd только там.
- Сборка одна: `make` в `src/vtm`, `unittest` для Python. Без CMake и пакетных
  менеджеров, пока они не понадобятся.
- Пересматриваем, если: появится троичное железо с C-драйверами (тогда ядра
  станут тоньше), или если Rust-экосистема для инференса за год сравняется.
