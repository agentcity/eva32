## Тестовые фикстуры (не модели, а данные тестов)

`data/parity_random/*.vtm`, `data/parity_cold/*/model.vtm`,
`tests/vtm/fixtures/*.vtm`, `fuzz-findings/*.vtm` — мелкие, нужны для паритета,
fuzz-регрессий и C-тестов. Не удалять.

## Удалено (пересобирается)

| Что | Размер | Почему удалено |
|---|---|---|
| `runs/cold/*` | 6,4 ГБ | холодная третизация: нечитаемый текст (см. `quantization-verdict.md`) |
| `export/*` | 7,9 ГБ | промежуточные `.trit`/`q4.bin` — восстанавливаются `cold_export.py`/`gguf_import.py` |

Пересборка: `python3 tools/cold_export.py --model ... --out ...` (третизация),
`python3 tools/gguf_import.py ...` (Q4 из ollama).

## Что не в репозитории, но нужно

- `.hfcache/` (7,7 ГБ) — HF-веса Qwen 0.5B/3B для экспорта. В git не попадает.
- `~/.ollama/models` (6,2 ГБ) — GGUF-модели. Источник для импорта.

## Правило на будущее

Крупные артефакты пишем **в `/tmp/<задача>`**, а не в `export/`: каталог может быть
удалён при чистке, и чужая работа пропадёт (так и случилось 2026-11-24 — потеряно
~40 минут импорта 7B).
