# Зоопарк моделей: что лежит и что из этого живое

> После чистки 2026-11-24 в репозитории остались только артефакты, которые
> действительно нужны. Всё нерабочее (холодная третизация, случайные веса,
> промежуточные экспорты) удалено — оно пересобирается одной командой.

## Рабочие

| Путь | Размер | Что | Статус |
|---|---|---|---|
| `runs/q4/3b.vtm` | 1,92 ГБ | Qwen2.5-3B, Q4 из GGUF (Q4_K_M → наш kind 5) | ✅ считает, 5–7 ток/с; качество чинится (0160) |
| `runs/q4/tokenizer.json` | 7 МБ | токенизатор Qwen2.5-3B | ✅ |
| `runs/tiny/model.vtm` | 4,9 МБ | наша QAT-модель 4M параметров | ✅ текст, но игрушечная |
| `runs/tiny/model_fp16.vtm` | 4,9 МБ | то же с fp16-масштабами | ✅ для сравнения |
| `demo/model.vtm` | 0,1 МБ | демо-эмбеддинг (vocab 128) | 🧪 **фикстура тестов**, не для чата; генерируется `make -C src/vtm test`, в списке чата скрыта |

## Тестовые фикстуры (не модели, а данные тестов)

`data/parity_random/*.vtm`, `data/parity_cold/*/model.vtm`,
`tests/vtm/fixtures/*.vtm`, `fuzz-findings/*.vtm` — мелкие, нужны для паритета,
fuzz-регрессий и C-тестов. Не удалять.

## Удалено (пересобирается)

| Что | Размер | Почему удалено |
|---|---|---|
| `runs/cold/*` | 6,4 ГБ | холодная третизация: нечитаемый текст (см. `quantization-verdict.md`) |
| `export/*` | 7,9 ГБ | промежуточные `.trit`/`q4.bin` — восстанавливаются `cold_export.py`/`gguf_import.py` |
| `runs/bench_shape/*` | 345 МБ | случайные веса для замера скорости — `bench_shape.py --synthetic` |

Пересборка: `python3 tools/cold_export.py --model ... --out ...` (третизация),
`python3 tools/gguf_import.py ...` (Q4 из ollama).

## Что не в репозитории, но нужно

- `.hfcache/` (7,7 ГБ) — HF-веса Qwen 0.5B/3B для экспорта. В git не попадает.
- `~/.ollama/models` (6,2 ГБ) — GGUF-модели. Источник для импорта.

## Правило на будущее

Крупные артефакты пишем **в `/tmp/<задача>`**, а не в `export/`: каталог может быть
удалён при чистке, и чужая работа пропадёт (так и случилось 2026-11-24 — потеряно
~40 минут импорта 7B).
