# Документация EVA32: индекс

> Актуально на 2026-11-27.

Одна строка на документ: что внутри и на какую дату он верен. Свежесть
проверяется механически — `python3 tools/check_docs_dates.py`: у каждого
документа должна быть строка «Актуально на ГГГГ-ММ-ДД», документ старше
30 дней или с датой из будущего валит проверку (шаг в CI рядом с
`check_vtm_docs.py`). Правило простое: **меняешь документ — ставь сегодняшнюю
дату**; если документ устарел, но ещё нужен, обнови его или пометь
«устарело, см. …» и поставь дату.

Реестр задач и статусы — [`ai/tasks/index.json`](../ai/tasks/index.json);
состояние проекта коротко — [status.md](status.md).

## Проверки

```bash
python3 tools/check_docs_dates.py     # даты + ссылки; старше 30 дней — exit 1
python3 tools/check_commands_doc.py   # справочник команд: плагины, фразы, разделы, индекс
python3 tools/check_vtm_docs.py       # опкоды и пути в docs/vtm.md — против кода
python3 tools/check_tasks.py          # реестр задач: id, файлы, разделы
python3 -m unittest tests.test_docs_fresh   # сам чекер, без зависимости от «сегодня»
```
